# crates

The crates workspace holding warlock's two Rust crates: warlock-engine, the freshness-tracking engine, and warlock-tui, the CLI and terminal UI built on it.

## Directories

- `warlock-engine/` — The freshness-tracking engine: walks repos, builds/validates .warlock.md, hashes/pacts directories, resolves scopes and sigils, drives drafting and pull-run state.
- `warlock-tui/` — Builds the `warlock` binary and library: CLI commands and interactive TUI, Linear/git integrations, agent wrapping, manifest/boundary logic.
