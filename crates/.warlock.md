# crates

The crates workspace holding warlock's two member crates: warlock-engine, the freshness ledger's core logic, and warlock-tui, the CLI, TUI and port implementations built atop it.

## Directories

- `warlock-engine/` — Core engine logic: scopes, sigils, pacting, filing, drafting, splitting, pulling, hashing and the document schema.
- `warlock-tui/` — Builds the warlock binary and warlock_tui library: CLI commands, TUI event loop/rendering, and pact/refresh/brief/draft/push/cut/pull ports.
