# crates

The crates directory holds the two Cargo packages that make up the workspace: warlock-engine, the core library for the ledger, fills, scopes and pulls, and warlock-tui, which builds the warlock binary and its commands.

## Directories

- `warlock-engine/` — The core library crate building and freshening the .warlock.md ledger, driving model-pass fills and mends, and enforcing the scope/sigil boundary; go here for ledger, fill, scope, pact or pull logic.
- `warlock-tui/` — The crate building the warlock binary: CLI entry point, TUI event loop and rendering, and the pact/refresh/scope/push/draft/pull/branch/key/brief commands; go here for any command or UI behaviour.

## Structure

- The warlock-engine crate: a Cargo package providing the core library that builds and freshens the ledger of a repo's .warlock.md documents, drives model-pass fills and mends, and enforces the scope/sigil boundary for writes and pulls.
- The warlock-tui crate: builds the warlock binary, defining the CLI entry point, the TUI event loop and rendering, and all commands (pact, refresh, scope, push, draft, pull, branch, key, brief) operating on the manifest, Linear and git.
- Cargo manifest for warlock-tui: builds the `warlock` binary (src/main.rs) and warlock_tui lib, depending on warlock-engine, ratatui, clap, notify.
