# crates

The crates workspace holding warlock's two Rust packages: the engine crate that tracks freshness and builds directory documents, and the TUI crate that provides the warlock CLI and interactive interface.

## Directories

- `warlock-engine/` — The freshness engine: builds/validates .warlock.md documents, hashes and pacts directories, resolves scopes and sigils, drives drafting, splitting and pull-run state.
- `warlock-tui/` — The warlock binary: CLI commands (pact, refresh, scope, key, branch, brief, push, draft, pull, resume, check) plus the TUI event loop against Git, Linear and a Claude agent.
