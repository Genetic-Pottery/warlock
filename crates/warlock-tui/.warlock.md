# warlock-tui

The warlock-tui crate: builds the `warlock` binary and library, providing the CLI commands (pact, refresh, scope, key, branch, brief, push, draft, pull, resume, config, check) and the interactive terminal UI that drives them, plus the Linear and git integrations, agent process wrapping, and manifest/boundary logic underneath.

## Files

- `Cargo.toml` (2.3 KB) — Cargo manifest for the warlock-tui crate: builds the `warlock` binary (src/main.rs) and warlock_tui lib, depending on warlock-engine plus ratatui, clap, notify, ureq, arboard, ctrlc.

## Directories

- `src/` — All crate source: CLI commands and the interactive TUI, Linear/git integrations, agent wrapping, manifest/boundary logic—go here for any question about a specific command, screen, or type.
