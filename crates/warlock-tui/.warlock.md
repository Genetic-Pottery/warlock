# warlock-tui

The warlock-tui crate: builds the `warlock` binary and the warlock_tui library, defining the CLI commands, the interactive TUI event loop and rendering, and the port implementations that drive pact/refresh, brief/draft/push/cut/pull.

## Files

- `Cargo.toml` (2.3 KB) — Crate manifest for warlock-tui: builds bin `warlock` (src/main.rs) and lib `warlock_tui` (src/lib.rs), depending on warlock-engine, ratatui, clap.

## Directories

- `src/` — CLI commands, TUI event loop/rendering, and port implementations (Claude, Linear, Git, Gh, watch) — open for pact/refresh, brief/draft/push/cut/pull, or panel logic.
