# warlock-tui

The warlock-tui crate: builds the `warlock` binary providing CLI entry points (pact, refresh, scope, key, branch, brief, push, draft, pull, resume, check) and an interactive TUI event loop and rendering, driving brief/chat/cut/pull workflows against Git, Linear and a Claude agent.

## Files

- `Cargo.toml` (2.3 KB) — Cargo manifest for the warlock-tui crate: builds the `warlock` binary (src/main.rs) and warlock_tui lib, depending on warlock-engine plus ratatui, clap, notify, ureq, arboard, ctrlc.

## Directories

- `src/` — CLI commands, TUI event loop and rendering, and engines for brief/chat/cut/pull against Git, Linear and Claude; look here for any behavior question.
