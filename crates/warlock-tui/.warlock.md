# warlock-tui

The warlock-tui crate: builds the warlock binary, defining the CLI entry point, the TUI event loop and rendering, and all commands (pact, refresh, scope, push, draft, pull, branch, key, brief) operating on the manifest, Linear and git.

## Files

- `Cargo.toml` (2.3 KB) — Cargo manifest for warlock-tui: builds the `warlock` binary (src/main.rs) and warlock_tui lib, depending on warlock-engine, ratatui, clap, notify.

## Directories

- `src/` — CLI dispatch, TUI loop/rendering and the pact/refresh/scope/push/draft/pull/branch/key/brief commands over manifest, Linear and git; go here for any command or UI behaviour.
