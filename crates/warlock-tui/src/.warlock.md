## Structure

- main.rs: CLI entry point: defines the warlock Cli/Command/subcommands (sigil, stale, fresh, check, pact, refresh, scope, key, branch, brief, push, draft/Cut, pull, resume) and the fn main/run dispatching to the tui's event loop.
- lib.rs: crate root: declares all modules and re-exports the public API surface (Account, brief, claude agents, git, linear, pull, push, query, etc.)
- interactive.rs: Interactive<S>: the TUI event loop wiring App, Pact, Chat, Pushes, Cutter and Puller to key/mouse input via Session<Live<S>>
- ui.rs: Lays out and draws the TUI frame: Cut/Shape geometry, tree/panel/composer/footer rendering, and Dialog for modals (help, push, cut, pull, review, carry, scope, record).
- push.rs: push.rs: push(scope, path) files a brief as a Linear project via prepare/file/sent; Prepared holds root, brief, destination, Key; would() renders the dry-run line.
- cut.rs: cut(): files a slice's drafts as Linear issues, wires blocking edges, posts CUT_NOTE/SKIP_NOTE comments; noted()/fold_title()/settled_as() parse those notes back on resume.
- pull.rs: `pull` command: selects a ticket (Selected, Chosen, Named, Taken), runs Pulling to completion via Ports, and reports progress through Progress/Watched to stdout and brief files
- pulling.rs: Pulling drives one ticket through split, sub-task loop and PR open/halt via `Pulling`, `Reached`, `Pulled`, `halt_comment`, `unchanged_comment`
- linear.rs: Linear GraphQL client: Client/Linear/Board trait with queries and mutations for projects, issues, labels, relations and comments; types Queue, QueuedIssue, Blocker, Priority, StateType, Error.
- git.rs: Runs git/gh subprocesses with timeouts (Spawner, Runs, Ran, Error) and defines Repository/Git, Forge/Gh, branch_name, commit_message, pull_request_title, pull_request_body.
- freshness.rs: Finds pact-stale directories touched by changed files and refreshes them via descend, committing only .warlock.md and manifest paths that changed.
- descent.rs: Descent enum (Pact/Refresh/Unpact) and descend(), which runs pact_subtree/refresh_subtree/unpact_subtree and saves the resulting manifest
