## Structure

- main.rs: CLI entry point: defines Cli/Command and subcommands (sigil, stale, fresh, check, pact, unpact, refresh, scope, key, branch, brief, push, draft/Cut, pull, resume), dispatches them, and runs the interactive TUI loop in run().
- interactive.rs: Interactive<S>: the TUI event loop wiring App, Pact, Chat, Pushes, Cutter and Puller into Session, handling press/point/paste/draw/keep_up
- ui.rs: Lays out and renders the TUI frame: Shape/Cut geometry, tree/panel/composer/footer drawing, and Dialog for all modal confirmations.
- cutting.rs: Cutter<O,A>: drives /draft's cutting flow — fetch/plan via Fetching, slice drafting/review/feedback/filing via Slicing<Stage>, confirm via CutConfirm/Review/Carry
- cut.rs: cut(): files a slice's Drafts as Linear issues, wires blocked_by/blocks/waits_on edges, comments CUT_NOTE/SKIP_NOTE, and parses them back via noted()/fold_title()/settled_as().
- pulling.rs: Pulling runs a ticket through PullRun/PullSubtask: split, work subtasks, commit, detect crossings, and open or report the pull request via Pulled/PullEvent.
- pacting.rs: Pact<P>: drives pact/unpact/refresh runs via spawn_pact/run_pact, drains PactEvent into App's account and Manifest, and applies Toggled outcomes (Toggled, Refusal, apply_toggle).
- claude.rs: Claude CLI agent: spawns `claude` subprocess, builds prompts/system prompts for chat, drafting, splitting and working; ClaudeAgent, ChatAgent, Conversation, Drafting, Splitting, Working, Cancel, Activities.
- linear.rs: Linear GraphQL client: Client/Posts send queries, Board trait and Linear<P> implement project/issue CRUD, queue, comment, and state lookups.
- git.rs: git.rs: process spawning (Spawner/Runs/Ran/Error), Git<R: Repository> wrapping git CLI (dirty, default_branch, cut_branch, commit_all, publish), branch_name/commit_message slugging, pull_request_body/HUMAN_GATE, and Gh<R: Forge> opening PRs via gh.
- boundary.rs: Operation and Verdict: permits() checks scope_covering/closed_scopes_at_or_below against held sigils to open, close, or ClosedBelow an operation
- check.rs: `check` and `gate` and the PreToolUse `hook`: resolve a path's scope/sigils/opens via route_facts, emit prose or JSON, deny closed-scope tool calls
