## Structure

- main.rs — CLI entry point: defines the Cli/Command tree (config, stale/fresh/check, pact/unpact/refresh, scope, key, branch, brief, push, draft, pull, resume) and dispatches to warlock_tui, with run() driving the interactive terminal event loop.
- lib.rs — crate root: declares all modules and re-exports their public types/functions (Account, Thread, Git, LinearClient, pull, push, brief, etc.)
- interactive.rs — Interactive<S>: the TUI's live event loop, wiring App, Pact, Chat, Pushes, Cutter and Puller to key/mouse input via Session::press/point/draw/keep_up.
- session.rs: reload/Scope/Watched lifecycle — reload(), Watched::round/caught_up, closed_scope, load_app/load_app_in building App, Scope, Tree, Manifest at startup.
- ui.rs — Renders the whole TUI frame: tree pane, panel, composer, footer, and the Dialog modal types, plus layout/hit-test helpers like areas, hit_test and panel_reach.
- input.rs — Translates key and mouse events into Action, Pressed and MouseAction variants, routing modal, composer, drag and panel/tree hit-testing input.
- pacting.rs — Pact<P> drives pact/unpact and refresh runs: press(), keep_up()/drain() stream PactEvent into the Panel account, apply_toggle() and described() turn a PactedSubtree into Toggled with refusals.
- running.rs — Drives pact/refresh commands: wires Cancel, ClaudeAgent and descend into a Progress-reporting run, turning pact::Failure lists into a Report and exit status.
- cutting.rs — Cutter<O,A> drives /draft: fetches a Planned project, loops slices through Drafting/Waiting/Reviewing/Filing/Carrying stages, and files or skips each slice via Cut and Skipping.
- pulling.rs — Pulling drives a ticket through split, sub-task sessions, crossing checks and PR opening via `Pulling`, `Pulled`, `Reached`, `PullEvent` and `halt_comment`.
- linear.rs — Linear GraphQL client: Client/Posts for HTTP, Board/Linear trait implementing queries and mutations, Queue/QueuedIssue/NamedIssue/FetchedProject types, and Error enum.
- git.rs — Spawner/Git/Gh process-running layer: Runs/Repository/Forge traits, Ran/Error/Commit/Dirty types, branch_name, commit_message, pull_request_body, HUMAN_GATE.
