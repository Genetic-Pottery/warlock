## Structure

- main.rs defines the clap Cli/Command subcommands and the run TUI event loop over the Session struct; lib.rs declares the modules and re-exports the public API.
- descent.rs drives one pact, refresh or unpact walk through descend() with a single manifest save; running.rs uses it for the headless pact and refresh commands.
- pacting.rs runs the p and r keys on a worker thread and drains PactEvent into panel sections and one reload after the run.
- boundary.rs holds the shared verdict() logic for sigil-scope refusals; session.rs enforces it through closed_scope on p, r and s, and edits.rs checks it through Opened.
- input.rs maps key and mouse events to actions; the confirm, prompt, composer, scoping, editing and viewing modules handle the resulting key presses.
- submission.rs classifies composer input into Submitted values; chatting.rs and writing.rs act on them, and claude.rs supplies the agent that runs them.
- ui.rs draws App, Panel and Thread state using colour.rs, wrap.rs and selection.rs.
- stubs.rs and fixture.rs provide test-only stubs and Tree fixtures.
