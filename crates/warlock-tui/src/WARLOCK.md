## Structure

- app.rs — App: front-end state — Row, PactIntent, Focus, Sigils, Chrome, RunHeader — flattening a Tree into rows via walk_of/reflow and reseat_on for reloads.
- main.rs — The impure shell: `Cli`/`Command` subcommand dispatch, `main`, `run`'s poll loop, and `Session`, which owns the terminal, app, pact and chat.
- boundary.rs — verdict()/Verdict/Reach: one boundary check shared by panel keys and headless doors, plus closed_scope_message and blocking_scopes_message for the refusal text
- descent.rs — One `descend` entry shared by pact/refresh/unpact via `Descent`, saving the manifest exactly once; `RunEvent` and the `Relay` observer relay engine hooks to panel and shell alike.
- pacting.rs — Pact worker: Pact<P>, Work, Running, PactEvent, CancelGuard, and drain() driving p and r as one worker thread with a single end-of-run reload.
- chatting.rs — Chat drives the one conversation: Chat<C>::say/ask/compose/keep_up run a turn, spawn_turn/run_turn/apply_turn own the worker thread, Chatting and TurnEvent carry it, Asked tags Answer vs Document.
- panel.rs — Panel: the account/thread/document three-card pane with Showing, Mode, Card<T>, panel_offset_for, swapped by next_card and filled via start_turn/refill_document/write_run.
- ui.rs — Draws one frame from explicit state via draw, plus the layout measurers tree_height, panel_height, run_header_height, composer_height, panel_width and hit_test, all cut through areas.
- session.rs — Owns Scope, Watched and reload/load_app: builds the tree session, reloads on watch events, and asks closed_scope the one boundary question for p/r/s.
- watch.rs — Filesystem watching: NodeSet filters events to walked paths, WatchPolicy decides when a reload is owed (QUIET_PERIOD, RELOAD_CEILING, COALESCED_RELOADS), Watch/Watching drive notify.
- claude.rs — Spawns and reads `claude`: ClaudeAgent runs passes, ChatAgent holds turns and Session, Cancel stops a run, Activities reports Activity, stream::read_line parses stream-json.
- lib.rs — Crate root re-exporting App, Panel, Composer, Thread, claude and watch types; the terminal-free front end assembled from the crate's modules.
