# src

This is the whole of `warlock-engine`'s source: one library crate (`lib.rs` is its root, no separate binary here) covering the domain vocabulary — the tree, the manifest, the freshness decision, the model-pass port, and the scope/sigil boundary. It touches the filesystem and reads file bytes to hash them, but opens no sockets and spawns no subprocesses; reaching a model is a trait implemented elsewhere, by a binary on the far side of the seam defined in `agent.rs`.

**`lib.rs`** (15,800 bytes) is the crate root. It declares the module list (`agent`, `briefs`, `claude_md`, `clock`, `decide`, `fitting`, `hash`, `ignores` and `languages` as private, `load`, `manifest`, `pact`, `scope`, `sigils`, `state`, `tree`) and re-exports the public surface of each with its own doc comment — this is where a reader finds, in one place, every type and function the crate intends outsiders to use, each with a one-paragraph account of what it does and does not do.

**`agent.rs`** (48,596 bytes) defines the `Agent` trait — one method, `run(&self, &Request) -> Result<Response, Error>`, plus `context_tokens()` with a `DEFAULT_CONTEXT_TOKENS` (128,000) default — the port through which the engine reaches a model without ever running one itself. It also defines `Request` (prompt, directory, `files: Vec<File>`, `child_documents: Vec<ChildDocument>`, `previous_document: Option<String>`, all built through `Request::new` and `with_*` builders), `File` (a path plus a private `Content` enum with four states reached through `File::present`, `File::omitted`, `File::elided`, `File::summarised`, and read back through `bytes()`, `kept()`, `summary()`, `size()`, `is_omitted()`), `ChildDocument` (a child directory's `WARLOCK.md`, verbatim), `Response` (just `text`), and `Error` (`NotFound`, `Failed`, `EmptyOutput`, `TimedOut`, `Io`, `#[non_exhaustive]`), with a `one_line` helper that flattens and excerpts stderr to `STDERR_EXCERPT` (200) characters for `Display`. The doc comment explains why the previous document is its own field rather than one of `files`: a file is evidence, a previous document is a claim, and conflating them let a false sentence from an earlier pass survive uncontradicted.

**`briefs.rs`** (21,752 bytes) reads `.warlock/briefs.toml` — a repository's opt-in statement of where it wants briefs written. `briefs_path` locates the file beside the manifest; `load_briefs` returns the configured directory or `DEFAULT_BRIEF_DIRECTORY` (`"docs"`) if the file or key is absent, and refuses (`Error::Syntax`, `Error::AbsoluteDirectory`, `Error::ParentDirectory`) rather than silently defaulting on anything malformed. `check_relative` walks path components rejecting `..` and absolute roots without touching the filesystem. The private `Briefs` struct and `default_directory` back the `serde` deserialisation. This module never writes anything.

**`claude_md.rs`** (44,982 bytes) writes `<root>/CLAUDE.md`, splicing a delimited block (`BEGIN`/`END` HTML-comment markers) into whatever is already there via the pure function `splice`, and only ever that block — `BODY` is the fixed text about what warlock is, what the three colours mean, and the scope/sigil vocabulary, written out in full as a `const`. `write_claude_md` is the one entry point: it reads any existing file, splices, and writes atomically through the same temp-file-then-rename idiom as the manifest (`manifest::temp_file_name` and `write_and_sync`). Returns `Written::Created` or `Written::Updated`; fails with `Error::Read`, `Error::NotText`, or `Error::Write`. Writes exactly this one file — no manifest, no `.warlock/`, no model pass.

**`clock.rs`** (15,763 bytes) is hand-rolled RFC 3339 UTC timestamp arithmetic (no date/time crate), because the manifest stores a grant's timestamp verbatim and never parses it back. `now_rfc3339` is the public entry point (infallible, even for a pre-epoch clock); `rfc3339_from_unix_seconds` and `civil_from_days` (Howard Hinnant's algorithm, transcribed) do the calendar math, clamped to `MIN_REPRESENTABLE`/`MAX_REPRESENTABLE` so the output is always exactly twenty characters.

**`decide.rs`** (11,206 bytes) is the staleness verdict: `decide_state(entry: Option<&PactEntry>, computed_hash: &str) -> NodeState`, a pure, total, infallible four-case function (no entry → `Unpacted`; entry with no or mismatched hash → `PactedStale`; entry with matching hash → `PactedFresh`). It takes both inputs from callers rather than computing either — the hash comes from `hash::subtree_hash`, and the only writer of a `granted_hash` anywhere in the crate is `pact::pact_subtree`/`pact::refresh_subtree` after a pass runs.

**`fitting.rs`** (189,298 bytes, summarised) owns the question of what goes into an `agent::Request` given two byte budgets. Its one entry point is `fit(prompt, directory, root, agent, observer) -> Result<Fitted, Error>`, returning a `Fitted { request, problems }`. Internally it walks a directory (`walk`, `WALK_DEPTH` = 2), gathers files and children's documents, and runs a four-rung ladder — whole, elided (via `languages::elide`), summarised (map-reduce through the `Agent` port, chunked with `chunk_utf8` under `CHUNK_BYTE_CAP`/`CHUNK_COUNT_CEILING`), and finally name-and-size — never truncating. Summaries are cached under `.warlock/summaries/`, keyed by content hash via `summary_key`, `summary_dir`, `summary_file_name`, `cached_summary`, `cache_summary`. Key constants: `PER_FILE_BYTE_CAP` (1 MiB), `request_byte_cap(context_tokens)`, `MINIMUM_SUMMARY_BYTES`. `Problem`/`Omission` report non-fatal per-file shortfalls (`TooLarge`, `OverBudget`, `Unreadable`, `NotText`, `TooManyChunks`, `Unsummarised`).

**`hash.rs`** (31,946 bytes) computes `subtree_hash(dir) -> Result<String, Error>`: a blake3 digest (domain-separated via `HASH_CONTEXT`) over every file's relative path and bytes at and below `dir`, in sorted-path order, following the same ignore rules as `load.rs` (`ignore` crate, `.warlockignore` via `ignores::is_ignored`, `.warlock/` pruned). `files_under` does the walk; `length` is a saturating byte-count helper. An unreadable file is deliberately `Error::Read`, never skipped, because skipping would hash identically to deletion — a design point the module doc spends real effort on. `Error` also has `Walk` and `Path` variants.

**`ignores.rs`** (5,278 bytes) is the narrow question `hash.rs` and `load.rs` both need answered: whether a directory *itself* is excluded by `.warlockignore`, since a walker never applies its own rules to the root it's handed. `is_ignored(path) -> Result<bool, ignore::Error>` does a one-deep walk of the parent (`walk_one_deep`) checking only `.warlockignore` (`FILENAME`), not `.gitignore` or hidden-file rules. A path with no parent, or not on disk, answers "not ignored."

**`languages.rs`** (24,923 bytes) is the per-language table behind `fitting`'s elision rung: which bytes of a source file a documenter doesn't need (test bodies), keeping test declaration lines (names) and dropping bodies, replaced by a marker line from `marker(lines)`. `elide(path, text) -> Option<Elided>` is the entry point; `Elided { text, dropped }`. Language rows live in a static `TABLE: &[Language]`, found by extension via `language_of`, each row specifying `test_suffixes`/`test_prefixes` (whole-file test conventions) and/or inline `blocks: &[Block]` (anchored-at-column-zero opener/closer pairs, e.g. Rust's `#[cfg(test)] mod tests { }`). Covers Rust, Zig, Go, TypeScript/JavaScript, Python, Ruby, Java/Kotlin/C#/Swift, and Elixir. An extension with no row is left completely alone — no guessing.

**`load.rs`** (74,320 bytes) builds a `Tree` from a real directory: `load_tree(working_dir) -> Result<Loaded, Error>`, where `Loaded { tree, problems: Vec<Problem> }`. Walks with the `ignore` crate rooted at `working_dir` (made absolute via `absolute`), reading the manifest from `repository_root` (nearest ancestor with `.git/`, found by `repository_root`). Every directory the walk reaches is a node (`Builder::node`); one with a `WARLOCK.md` (`DOCUMENT_FILE`) is documented, others have `document: None`. `.warlockignore`-excluded directories keep their row but are marked `Node::ignored` via `mark_excluded`, which runs the same walk twice with and without the custom ignore filename registered. State comes from `Builder::state_of` (calls `decide_state` against `subtree_hash`, pushing a `Problem` with `ProblemCause::Hash` on failure rather than ever comparing partial data) and scope from `Builder::scope_of` (validates via `validate_scope`, pushing `ProblemCause::Scope` and leaving the node unscoped on failure — never correcting the manifest). `walk`, `builder`, `mark_excluded` and the private `Directory`/`Builder` structs do the mechanics.

**`manifest.rs`** (63,300 bytes) is the in-memory shape of `.warlock/pacts.toml` and the read/write logic. `Manifest { version, entries: Vec<PactEntry> }` with `Manifest::new`, `with_entries`, `entries`, `entry`, `push`, `to_toml_string`/`from_toml_str`, and the disk operations `Manifest::save`/`Manifest::load` (atomic write via temp-file-then-rename, `Error::NotFound` distinct from a corrupt file). `PactEntry` holds `module`, `document`, `scope`, `granted_hash`, `granted_at`, all private, reached through `PactEntry::new` (which normalises paths via `to_manifest_path`), `with_grant`/`without_grant`, `with_scope`/`without_scope`, and crate-private `stored`/`overwrite_run_fields` (used by pact runs, which never touch `scope` — that field survives every pact/refresh because no run-owned setter reaches it). Free functions `to_manifest_path`, `from_manifest_path`, `manifest_path` do path translation to/from the manifest's relative-forward-slash form (`ROOT_MODULE` = `"."` for the repo root); `temp_file_name` and `write_and_sync` are the shared atomic-write idiom reused by `claude_md.rs`, `sigils.rs`, and `pact.rs`. `SCHEMA_VERSION` = 1, enforced strictly (`Error::UnsupportedVersion`) via `deserialize_version` and checked again in `from_toml_str`.

**`pact.rs`** (327,383 bytes, summarised) is the pacting subsystem proper, layered as `pact_directory` (one directory: gather → describe oversized files → fit to budget → one agent pass → write `WARLOCK.md` verbatim, stamped with a `STAMP` preamble), `pact_subtree` (children-first walk, writes documents then hashes and grants, cancellable per-directory through an `Observer` trait returning `Pacting::Continue`/`Stop`), and `refresh_subtree` (same machinery restricted to directories `decide_state` calls stale, leaving fresh ones untouched). Also here: `unpact_subtree` (drops manifest entries, leaves documents on disk), `closed_scopes_at_or_below` (the downward half of the boundary question), and `view_file` (reads a file for a person, capped at `PER_FILE_BYTE_CAP`, returns `Viewed{text, cut}`). Key public types: `PactedSubtree`, `Pacted`, `Unviewable`, `Refusal`, `Error`, `Failure` (all `#[non_exhaustive]` with `Display`/`Error` impls), plus `MINIMUM_DOCUMENT_BYTES` = 200 (a length floor, not a quality check). `MANIFEST_DIR`, `DOCUMENT_FILE`, `PROMPT` and `STAMP` are the module's own constants (spelled again here rather than imported, per the source given — worth checking against `load.rs`'s and `manifest.rs`'s own copies of `MANIFEST_DIR`/`DOCUMENT_FILE` if that ever matters to a change). This is easily the largest file in the directory.

**`scope.rs`** (36,980 bytes) is the sole authority on what a scope string may be. `validate_scope(&str) -> Result<(), Rule>` judges (never normalises) against: 1–24 characters, ASCII lowercase/digits/`-`/`_`, starts with a letter, doesn't end with a separator; `Rule` is the one-line-renderable reason it failed. `validate_sigil` is `validate_scope` plus acceptance of the wildcard `*` (`WILDCARD`). `RULES` is the one canonical hint string every prompt shows. `scope_covering(path, root, manifest) -> Result<Option<&str>, manifest::Error>` walks a path's manifest-relative ancestors (`at_or_above`) to the nearest one carrying a valid scope — nearest wins outright, never accumulates — stepping over invalid scopes via `valid_scope_on`/`valid_scope` (the latter `pub(crate)`, reused by `pact.rs`'s `closed_scopes_at_or_below`). `scope_opens_to(covering, held)` is the separate membership test: `None` (unscoped) is always open; an empty `held` opens nothing scoped; `*` in `held` opens everything.

**`sigils.rs`** (32,931 bytes) is the machine-local mirror of `scope.rs`: sigils live at `<home>/.warlock/<project>/config.toml`, never inside the repository, keyed by `project_directory(root)` (a blake3 digest of the canonicalized root path, domain-separated by `PROJECT_CONTEXT`, combined with a readable name via `readable_name`, capped at `MAXIMUM_NAME_CHARACTERS`/`DIGEST_CHARACTERS`). `sigils_path`, `load_sigils` (missing file is `Error::NotFound`, not an empty set — same asymmetry as `Manifest::load`), `save_sigils` (atomic write, replaces the whole set). The private `Config { sigils: Vec<String> }` struct backs serde; `home` is always a caller-supplied parameter, never read from the environment.

**`state.rs`** (3,943 bytes) declares the three-variant `NodeState` enum (`Unpacted`, `PactedStale`, `PactedFresh`) — no fourth "unknown" state by design — with `NodeState::ALL` and `is_pacted()`.

**`tree.rs`** (35,718 bytes) is pure shape: `Node { path, document, state, ignored, scope, children, files }` built via `Node::new` plus `with_children`/`with_files`/`with_ignored`/`with_scope` (all builder-style, `#[must_use]`), `is_leaf()`; the `IntoDocument` trait lets `Node::new` accept `PathBuf`/`&Path`/`&str`/`String`/`Option<PathBuf>` uniformly. `Tree { root: Node }` wraps a root and offers `root_path`, `walk()` (returns `DepthFirst`, a depth-first parents-before-children iterator), `counts()` (returns `StateCounts`, one field per state), and `find(path)`. Nothing here touches a filesystem or computes state — `load.rs` is what populates a `Tree` from disk.

## How the pieces fit together

The dependency shape is: `state.rs` and `tree.rs` are pure data types with no knowledge of disk or manifest; `manifest.rs` and `hash.rs` are independent I/O primitives; `decide.rs` is a pure function combining one `PactEntry` (from `manifest.rs`) with one hash (from `hash.rs`); `load.rs` composes all four (plus `ignores.rs` and `scope.rs`) into `load_tree`, the read path that produces the coloured tree a front end renders. `agent.rs` defines the model-pass port with no implementation; `fitting.rs` (using `languages.rs` and `ignores.rs`) decides what goes into a request against that port's budget; `pact.rs` is the write path, composing `fitting.rs`, `agent.rs`, `manifest.rs`, `hash.rs`, and `scope.rs` into the three top-level operations (`pact_directory`, `pact_subtree`, `refresh_subtree`) plus `unpact_subtree` and `view_file`. `scope.rs` and `sigils.rs` together are the boundary vocabulary — repository-side scopes and machine-side sigils — kept deliberately in separate files with separate storage so neither can be written to the other's home. `clock.rs`, `claude_md.rs` and `briefs.rs` are smaller, mostly self-contained utilities: a timestamp formatter, a `CLAUDE.md` writer, and a brief-directory config reader, each touching only their own one file on disk.
