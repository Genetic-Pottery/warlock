## Structure

- Defines the Agent trait and Request/Response/File/ChildDocument/Error types forming the model-pass port, with no subprocess behind it.
- Reads briefs.toml via briefs_path/load_briefs, defaulting to DEFAULT_BRIEF_DIRECTORY and rejecting absolute or `..` directory settings.
- Writes CLAUDE.md by splicing a fixed orientation section between BEGIN/END markers, preserving surrounding bytes.
- now_rfc3339 turns SystemTime into a fixed 20-byte UTC RFC3339 string via civil_from_days.
- decide_state(entry, computed_hash) -> NodeState combines a manifest PactEntry with a computed hash.
- Fills, checks, mends and renders WARLOCK.md documents using Fill, Entry, Described, Evidence, Defect, Repair and accept/mend/render.
- Builds a directory's pact request from disk via own_files, child_documents, measured, one_file and carry_hash, explaining omissions via Problem/Omission.
- subtree_hash and file_hash compute blake3 digests using the same walk as the loader.
- load_tree in load.rs walks a repo into a Tree of Node using manifest state, scopes and .warlockignore, calling ignores.rs's is_ignored and reading manifest.rs's Manifest.
- Manifest and PactEntry read and atomically save .warlock/pacts.toml, tracking scope, granted_hash and carry_hash per file.
- pact_subtree, refresh_subtree, pact_directory and unpact_subtree/unpact_ignored drive the per-directory and per-file pass, calling into document.rs's Fill/mend and fitting.rs's request-building.
- scope.rs's Rule, validate_scope, validate_sigil, scope_covering and scope_opens_to are read by load.rs when assigning per-node scope and consulted by sigils.rs for sigil matching.
