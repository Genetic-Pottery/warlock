This is a Rust module defining warlock's binary-level error vocabulary, centered on a public(crate) enum `Error` and supporting items, plus a `#[cfg(test)]` test module.

The module doc comment states `Error` is the whole error vocabulary reaching `main`, and that `one_line` is the flattening every variant's `Display` relies on to guarantee a single printed line.

Imports come from `std::path::PathBuf`, `std::{fmt, io}`, the `warlock_engine` crate (`claude_md`, `load`, `manifest`, `pact`, `scope`, `sigils`), and `crate::boundary::{blocking_scopes_message, closed_scope_message}`.

The enum `Error` (`#[derive(Debug)]`, `pub(crate)`) has these variants, each documented at length with design rationale:

- `WorkingDirectory { source: io::Error }`
- `Load { source: load::Error }`
- `Problems { first: String, rest: usize }` — flattened text of a load's non-fatal problems
- `Manifest { source: manifest::Error }`
- `Unspellable { source: manifest::Error }` — path with no repository-relative form
- `ClosedScope { path: String, scope: String }` — headless write refused by boundary; reuses `closed_scope_message`; notably maps to exit status 3 (per `status_for` in crate root, referenced not shown)
- `ClosedScopeBelow { path: String, scopes: Vec<String> }` — un-pact blocked by descendant scopes; reuses `blocking_scopes_message`
- `Scope { rule: scope::Rule }` — invalid scope text from `warlock scope add`
- `NoPact { module: String }` — scope write aimed at directory with no manifest entry
- `Pact { source: pact::Error }` — whole headless run failed to start (walk failure)
- `Failures { failed: usize, total: usize }` — run finished with some directories failed; exit status 4
- `Cancelled` — run stopped via Ctrl-C; exit status 130
- `Signal { source: ctrlc::Error }` — Ctrl-C handler could not be installed; exit status 1
- `NoRepository { start: PathBuf, wanted: &'static str }` — no `.git` found; shared by `init` and `config` subcommands
- `ClaudeMd { source: claude_md::Error }`
- `NoHome` — no `HOME`/`USERPROFILE` found (carries nothing)
- `Prompt { source: io::Error }` — stdin read failure for `warlock config`
- `Sigil { entered: String, rule: scope::Rule }` — invalid sigil input
- `Sigils { source: sigils::Error }`
- `Terminal { source: io::Error }`

An `impl Error` block provides one associated function: `pub(crate) fn from_problems(problems: &[load::Problem]) -> Option<Self>`, which builds `Error::Problems` from the first problem (via `one_line`) and a count of the rest, returning `None` if `problems` is empty.

A free function `pub(crate) fn one_line(message: &str) -> String` collapses a multi-line diagnostic message to one line by taking the first non-empty trimmed line and, if there are further lines, appending the last one joined with `": "`; returns empty string if there are no lines.

`impl fmt::Display for Error` implements `fmt` matching every variant, each with inline comments explaining wording choices (e.g., delegating to engine's own `Display`/`one_line` flattening for `Load`, `Manifest`/`Unspellable` (shared arm), `Pact`, `ClaudeMd`, `Sigils`; pluralizing "directory"/"directories" in `Failures`; reusing `closed_scope_message` and `blocking_scopes_message` verbatim for `ClosedScope`/`ClosedScopeBelow`; custom sentences for `NoRepository`, `NoHome`, `Sigil`, `NoPact`, `Cancelled`, `Signal`; `Problems` has two match arms distinguishing `rest: 0` vs nonzero).

`impl std::error::Error for Error` implements `fn source(&self) -> Option<&(dyn std::error::Error + 'static)>`, returning `Some(source)` for variants carrying an underlying error (`WorkingDirectory`, `Terminal`, `Prompt`, `Load`, `Manifest`/`Unspellable`, `Pact`, `ClaudeMd`, `Sigil`/`Scope` via their `rule` field, `Sigils`, `Signal`), and `None` for `Problems`, `NoRepository`, `NoHome`, `ClosedScope`, `ClosedScopeBelow`, `NoPact`, `Failures`, `Cancelled`.

`impl From<io::Error> for Error` converts into `Error::Terminal { source }`, documented as covering everything reached by `?` once the terminal is up.

The `#[cfg(test)] mod tests` block imports `PathBuf`, engine types (`claude_md, manifest, scope, sigils`), `super::{Error, one_line}`, and `crate::standing::{FOR_CLAUDE_MD, FOR_SIGILS}`. It defines a constant `PROBLEM: &str` (a sample multi-line problem message) and numerous `#[test]` functions verifying: `one_line` behavior on already-single-line and multi-line/parser-diagnostic input; `Error::from_problems` on empty and non-empty slices; `Problems` display with `rest: 0` and `rest: 3`; a broad test `every_message_is_one_line_so_it_prints_as_one` constructing an array of many `Error` variants and asserting none contain `\n` or are empty; and individual tests asserting exact `Display` wording for `Manifest`, `Unspellable`, `NoRepository` (both `FOR_CLAUDE_MD` and `FOR_SIGILS`), `Sigil`, `Scope` (using `warlock_engine::validate_scope` to produce a real `Rule`), `NoPact`, `NoHome`, `Sigils`, and `ClaudeMd`.
