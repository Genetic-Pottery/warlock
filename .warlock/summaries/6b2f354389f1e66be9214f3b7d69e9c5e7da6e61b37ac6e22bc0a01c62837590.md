This is the complete (and only) part of `edits.rs`, a Rust module implementing the headless CLI writes for warlock: `warlock unpact <path>`, `warlock scope add <path> <scope>`, and `warlock scope remove <path>`.

**Module-level doc comments** explain the design at length: these are the first subcommands that mutate `.warlock/pacts.toml`; the boundary (scope/sigil) check must run before path spelling or manifest inspection to avoid leaking repository shape to a closed-off caller; refusals exit with status 3 (boundary refusal, unrecoverable without a sigil) versus 1 (ordinary failure); un-pacting drops manifest entries only, never touches `WARLOCK.md` files; scope validation folds case via `to_ascii_lowercase` before calling `validate_scope`; an un-pact of a directory with no descendant scope conflicts succeeds even in an empty/unpacted repository.

**Public/crate-visible items** (all `pub(crate)` unless noted):

- `struct Opened` — private fields `repo_root: PathBuf`, `manifest: Manifest`, `target: PathBuf`, `sigils: Sigils` (all private/undocumented as pub). This is the gate type proving the boundary was checked.
  - `Opened::new(repo_root: PathBuf, home: Option<&Path>, manifest: Manifest, target: PathBuf) -> Result<Self, Error>` — pub(crate), the sole constructor, checks the boundary via `verdict`/`Verdict::Closed`, returns `Error::ClosedScope` on refusal.
  - `Opened::repo_root(&self) -> &Path` — pub(crate) getter.
  - `Opened::manifest(&self) -> &Manifest` — pub(crate) const getter.
  - `Opened::target(&self) -> &Path` — pub(crate) getter.
  - `Opened::unpacted(&self) -> Result<String, Error>` — private method; performs the actual un-pact via `unpact_subtree`, checks `Verdict::ClosedBelow` for descendant scope conflicts (`Error::ClosedScopeBelow`), saves manifest, returns success line from `unpacted_line`.
  - `Opened::scoped(&self, scope: &str) -> Result<String, Error>` — private; folds/validates scope, calls `with_scope_on`, saves, returns `scoped_line`.
  - `Opened::unscoped(&self) -> Result<String, Error>` — private; clears scope via `with_scope_on(..., None)`, returns `unscoped_line`.
  - `Opened::scope_on(&self, module: &str) -> Result<Option<&str>, Error>` — private helper, looks up entry's current scope, errors `Error::NoPact` if absent.

- `fn opened(wanted: &'static str, path: &Path) -> Result<Opened, Error>` — pub(crate), resolves environment (working dir, repo root, manifest, home) via `Standing`, then calls `Opened::new`.

- `fn unpact(path: &Path) -> Result<(), Error>` — pub(crate), the `warlock unpact` entry point; prints `warlock: {line}` and returns `Ok(())`.

- `fn scope_add(path: &Path, scope: &str) -> Result<(), Error>` — pub(crate), `warlock scope add` entry point.

- `fn scope_remove(path: &Path) -> Result<(), Error>` — pub(crate), `warlock scope remove` entry point.

- `fn unpacted_line(path: &str, dropped: &[&PactEntry]) -> String` — private, formats the "N entries dropped, M scoped (...)" success sentence.

- `fn scoped_line(module: &str, scope: &str, was: Option<&str>) -> String` — private, formats scope-add success sentence, noting prior scope if different.

- `fn unscoped_line(module: &str, was: Option<&str>) -> String` — private, formats scope-remove success sentence.

**Imports** used include `warlock_engine::{Manifest, PactEntry, unpact_subtree, validate_scope}`, `warlock_tui::Sigils`, and crate-internal modules `boundary` (`Reach`, `Verdict`, `verdict`), `error::Error`, `query::spelled`, `scoping::with_scope_on`, `session::sigils_under`, `standing::{FOR_SCOPE_ADD, FOR_SCOPE_REMOVE, FOR_UNPACT, Standing}`.

**Test module** (`#[cfg(test)] mod tests`) is extensive, defining private test-only constants `HASH`, `AT`, `HELD`, `CLOSED`, and helper functions: `a_dir`, `entry`, `a_manifest`, `a_repository`, `holding`, `manifest_bytes`, `unpact` (test helper wrapping `Opened`), `scope_add` (test helper), `scope_remove` (test helper), `stored`, `refusal`, `a_manifest_of_boundaries_both_ways`, `a_repository_of_boundaries`, `a_panel_over`, `as_the_shell_says_it`, `panel_answer`, `shell_answer`, plus an `enum Answer { WentAhead, Refused(String) }`. Tests cover: successful subtree un-pact leaving documents intact; closed-boundary refusal leaving manifest byte-identical; machine holding no sigils being refused everywhere scoped; success-line naming of dropped scoped entries; descendant-boundary refusal (`ClosedScopeBelow`) naming every scope in the way; un-pacting an empty/never-pacted repo; scope-add folding/validating/writing/moving boundaries; scope-remove idempotence; ordering guarantees (boundary asked before manifest existence checks) for both scope writes and un-pact; parity test asserting the TUI's `p` key (`pressed_p` from `crate::pacting`) and the shell's `unpact` agree exactly on every case. It imports test-support items from `warlock_engine` (`Node`, `NodeState`, `Tree`, `manifest_path`, `save_sigils`), `warlock_tui::App`, and crate modules `pacting::pressed_p`, `boundary::closed_scope_message`, `session::{load_manifest, sigils_under}`, `status_for`.
