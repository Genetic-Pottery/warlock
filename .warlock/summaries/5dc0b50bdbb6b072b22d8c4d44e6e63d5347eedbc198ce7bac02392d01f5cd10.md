This file implements the "when the disk moves" watching machinery for warlock, split into a pure timing/filtering half and an impure OS-facing half.

Module-level doc comments frame two questions: *which* filesystem movements matter (answered by `NodeSet`, built from the last successful tree walk, with no independent gitignore logic) and *when* to act on them (answered by `WatchPolicy` using three named constants). It stresses that `Instant::now` is never called in this file — callers hand in instants — and that no reload is ever performed here, only signaled as owed.

Imports: `std::collections::HashSet`, `std::fmt`, `std::path::{Path, PathBuf}`, `std::sync::mpsc::{self, Receiver, TryRecvError}`, `std::time::{Duration, Instant}`, `notify::{Event, RecommendedWatcher, RecursiveMode, Watcher as _}`, and `warlock_engine::{Tree, manifest_path}`.

Public constants (all `pub`):
- `QUIET_PERIOD: Duration` = 250ms — debounce quiet time.
- `RELOAD_CEILING: Duration` = 2s — max delay before forcing reload during a burst.
- `COALESCED_RELOADS: usize` = 1 — number of extra reloads owed for events arriving during a reload.

`NodeSet` (public struct, `Debug, Clone, Default, PartialEq, Eq`): holds private field `directories: HashSet<PathBuf>`. Public methods: `from_tree(tree: &Tree) -> Self` (builds from `tree.walk()` node paths), `accepts(&self, path: impl AsRef<Path>) -> bool` (true if immediate parent is in set), `len(&self) -> usize`, `is_empty(&self) -> bool`.

`WatchPolicy` (public struct, `Debug, Clone`): private fields `watched: NodeSet`, `burst_began: Option<Instant>`, `last_event: Option<Instant>`, `reloading: bool`, `moved_during_reload: bool`. Public methods: `new(tree: &Tree) -> Self`, `follow(&mut self, tree: &Tree)`, `watched(&self) -> &NodeSet`, `saw(&mut self, path: impl AsRef<Path>, at: Instant) -> bool`, `accepted(&mut self, at: Instant)` (escape hatch for non-tree paths like the manifest), `due(&self, now: Instant) -> bool`, `reload_started(&mut self)`, `reload_finished(&mut self, at: Instant)`, `owes_reload(&self) -> bool`.

`Watching` (public enum, `Debug`): variants `Live(Watch)` and `Off(String)` (failure reason as plain string, no `notify` type exposed).

`Watch` (public struct): private fields `_handle: RecommendedWatcher`, `events: Receiver<PathBuf>`, `live: bool`. Public methods: `start(root: impl AsRef<Path>, repo_root: impl AsRef<Path>) -> Watching` (starts recursive watch on `root`, plus attempts to watch the manifest via `watch_manifest`), `drain(&mut self) -> Vec<PathBuf>` (non-blocking, sets `live = false` on disconnect), `live(&self) -> bool`. Implements `fmt::Debug` manually (prints only `live` field via `debug_struct("Watch")...finish_non_exhaustive()`).

Private free function `watch_manifest(handle: &mut RecommendedWatcher, repo_root: &Path)`: tries to watch `manifest_path(repo_root)` non-recursively, falls back to its parent directory, else does nothing; reports no result.

Test module `tests` (`#[cfg(test)]`): private constants `TICK_MS`, `SLACK`, `LONG_AFTER`; private type alias `Event = (u64, &'static str)`; helper functions `walked() -> Tree` (builds a sample repo/crates/engine tree), `drive(policy, events, until_ms, reload_ms) -> Vec<u64>` (simulated event-loop driver), `gap(from_ms, to_ms) -> Duration`. Numerous `#[test]` functions covering `NodeSet` acceptance/rejection, filter replacement via `follow`, debounce/coalescing/ceiling behavior of `WatchPolicy`, rejected events, and `accepted` for out-of-tree paths like the manifest.

Nested private submodule `tests::live` (real filesystem tests, uses `std::sync::atomic::{AtomicUsize, Ordering}`, `std::{env, fs, process}`, imports `super::super::{Watch, Watching}`): private helper `scratch(name: &str) -> std::path::PathBuf` (creates a unique temp scratch directory), and two `#[test]` functions: `a_watcher_that_cannot_be_started_is_a_value_and_not_an_error` and `a_watcher_over_a_real_directory_starts_and_has_nothing_to_say_yet`, exercising `Watch::start`, `Watching::Off`, `Watching::Live`, `watch.live()`, and `watch.drain()`.
