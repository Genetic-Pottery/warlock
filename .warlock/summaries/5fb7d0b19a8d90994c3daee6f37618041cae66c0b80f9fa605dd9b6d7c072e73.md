These CONTENTS are the whole of `pacting.rs`, the module driving the pact key and the refresh key from a keystroke through a worker thread to a saved manifest and a reload, with an extensive `#[cfg(test)]` module attached.

**Module doc comment** frames the file: the pact key is the one keystroke slow enough to need a worker thread; `Pact` is the type the event loop keeps, and its four-part surface is `Pact::press`, `Pact::keep_up`, `Pact::stop`, and `Pact::running`. It draws the parallel to `Chat` (in `crate::chatting`), explains that the refresh key shares the same machinery via the `Work` enum, that one run at a time is a property of `Pact` itself, and that Esc cancels (through `CancelGuard`) while quitting drops the guard outright.

**Imports** come from `std`, from `warlock_engine` (`Agent`, `Manifest`, `NodeState`, `PactedSubtree`, `Pacting`, `Tree`, `fitting`, `pact`, `to_manifest_path`), from `warlock_tui` (`Activities`, `Activity`, `App`, `Cancel`, `ClaudeAgent`, `Outcome`, `PactToggle`, `Run`, `Section`, `Sigils`, `Wired`), and from sibling crate modules `crate::boundary` (`Reach`, `Verdict`, `verdict`), `crate::descent` (`Descent`, `carry_on`, `descend`), `crate::error::one_line`, `crate::session` (`Scope`, `closed_scope`, `reload_tree`).

**Constants**: `PACT_LOST` (footer text for a worker that stopped without reporting — implying a panic) and `PACT_CANCELLED` (footer text for a run stopped via Esc).

**Core public(crate) types**:
- `Pact<P>` struct — fields `agent: P` (private) and `run: Option<Running>` (private). Methods: `new()`, `with_agent(agent)` (impl on `Pact<ClaudeAgent>` and generic `impl<P: Wired + Agent> Pact<P>`), `#[cfg(test)] with_run(run)`, `running()` (const), `stop()`, `press(kind, app, manifest, scope, now)`, `keep_up(app, manifest, scope, now) -> Option<Reloaded>`.
- `Reloaded(pub(crate) Option<Tree>)` tuple struct — signals a run ended this round and carries the reloaded tree (or `None` if reload failed).
- `Running` struct (pub(crate)) — fields `events: Receiver<PactEvent>`, `cancel: CancelGuard`, `work: Work`, `before: App`.
- `Work` enum (pub(crate)) — variants `Pact(PactToggle)` and `Refresh(PathBuf)`; methods `path()`, `descent() -> Descent` (const), `kind() -> Run` (const), `is_cancellable()` (private, const).
- `CancelGuard` struct (pub(crate)) — field `cancel: Cancel` (private). Methods: `new()`, `handle()`, `cancel()`, `is_cancelled()` (private). Implements `Drop`.
- `PactEvent` enum (pub(crate), `Debug`) — variants `Starting { directory, position, total }`, `Doing(Activity)`, `Summarising { file, part, parts }`, `Requesting { files, bytes }`, `Documented { directory }`, `Finished(Result<Toggled, String>)`.
- `Reporting<'a>` struct (private) — fields `events: &'a Sender<PactEvent>`, `cancel: &'a Cancel`; implements `pact::Observer` with methods `starting`, `summarising`, `requesting`, `documented`.
- `Toggled` struct (pub(crate), `Debug`) — fields `manifest: Manifest` (private), `granted: bool` (private), `message: Option<String>` (private), `refusals: Vec<Refusal>` (private).
- `Refusal` struct (private, `Debug`) — fields `directory: PathBuf`, `reason: String`; implements `From<&pact::Failure>`.

**Free functions** (mostly private, some `pub(crate)`):
- `activity_port(events) -> Activities` — private.
- `spawn_pact(manifest, repo_root, work, agent, cancel) -> Receiver<PactEvent>` — pub(crate); spawns the worker thread via `thread::spawn` calling `run_pact`.
- `start_run(work, before, manifest, repo_root, agent) -> Running` — private.
- `run_pact(manifest, repo_root, work, agent, cancel, events)` — private; the worker thread body.
- `cancelled(toggled: Toggled) -> Toggled` — private, rewords a `Toggled` as a cancelled outcome.
- `pact_press(app, manifest, repo_root, sigils, in_flight, at) -> Option<PactToggle>` — private, extensively documented; handles the pact key's refusals (in-flight, closed scope, blocked un-pact).
- `blocked_unpact(app, manifest, repo_root, sigils) -> bool` — private.
- `#[cfg(test)] pub(crate) fn pressed_p(app, manifest, repo_root, sigils) -> Option<PactToggle>` — test seam wrapping `pact_press`.
- `refresh_press(app, manifest, repo_root, sigils, in_flight, at) -> Option<PathBuf>` — private.
- `drain(run, app, manifest, scope, now) -> Option<Reloaded>` — private; the core "apply everything since last round" logic called by `Pact::keep_up`.
- `DOCUMENT_FILE: &str = "WARLOCK.md"` constant (private).
- `close_account(app, scope, refusals, cancelled, now)` — private.
- `section_outcome(section, refusals, root) -> Outcome` — private.
- `restore(app, before, message)` — private.
- `section_label(root, directory) -> String` — private, uses `to_manifest_path`.
- `apply_toggle(manifest, repo_root, work, agent, observer) -> Result<Toggled, String>` — private; core engine-call dispatcher using `descend`.
- `described(subtree: PactedSubtree) -> Toggled` — private.
- `pact_message(failures, problems) -> Option<String>` — private, footer summary line builder.
