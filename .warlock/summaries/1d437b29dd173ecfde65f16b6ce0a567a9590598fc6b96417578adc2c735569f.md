This file implements the front-end application state for a terminal UI that displays a codebase's tree of `WARLOCK.md` documentation-freshness status, plus an extensive embedded test module validating that state.

It opens with a module-level doc comment laying out the design philosophy: the engine's tree walk is flattened into `Row`s for display, with the full walk (`all_rows`) kept separate from the filtered/drawn rows (`rows`); collapsed directories are tracked by path, not index, so they survive rebuilds; a "pacted-only" filter and a "show files" flag work by filtering-and-reflattening rather than mutating the tree; file rows carry no document/children and inherit their directory's colour; scrolling is kept in sync with selection via a pure function; a status message holds one line about the last keystroke, cleared on the next movement; a `Focus` enum decides which of two panes (tree/panel) keyboard input drives; pointer/mouse operations get their own methods distinct from keyboard ones; a subtree pact-in-progress is tracked separately from the transient message since it persists across keystrokes; and an `Account` (run history) and document-viewing each have their own scrollable "card" with follow-mode computed on demand.

Imports draw on the standard library, `warlock_engine` types (`NodeState`, `StateCounts`, `Tree`, etc.), and crate-local `Account`, `Line`, `wrapped`.

**Core types.** `Row` is one flattened tree line, carrying depth, path, document, state, child count, file/document-row/ignored flags, and its own (never-inherited) pact scope, built via `Row::new`/`Row::file` and builder methods. `PactToggle` reports the result of toggling a pact. `Run` distinguishes `Pact` vs `Refresh` runs sharing one in-flight record. `InFlight` (private) tracks an active run's path/position/total/kind, exposed only as a yes/no. `Summarising` (private) tracks a chunked summarization pass, contributing only footer wording. `Focus` (`Tree`/`Panel`) governs which pane keys drive. `Sigils` (`Nothing`/`Held(Vec<String>)`/`Unknown`) describes what sigils the machine holds, with a `line()` method matching `warlock config`'s wording. `Chrome` holds header/sigil state fixed per session, built via `Chrome::of`.

The `App` struct itself holds `all_rows`, `rows`, `collapsible`, `counts`, `selected`, `scroll_offset`, and three grouped private sub-states: `Viewpoint` (collapsed set, pacted_only, show_files, viewport_height, focus), `Status` (message, in_flight, summarising, pact_refused, mouse_captured), and `Panel` (two "cards" — `account: Card<Account>` and `document: Card<Vec<Line>>` — plus `showing: Showing`, height, width). `Card<T>` (private generic) holds content, scroll offset, and a follow flag, with methods to place content, compute line counts/windows/offsets. The `Shown` trait abstracts "has lines a panel window can cut from," implemented for `Account` and `Vec<Line>` (the latter via a `rows_of` word-wrapping helper).

**`impl App`.** Constructors (`from_tree`, `from_rows`, `with_collapsed`, `with_counts`); message/status accessors and setters for pact/refresh progress and refusal; panel/account/document methods (`start_account`, `show_document`, `refill_document`, `swap_card`, `has_account`/`has_document`/`has_panel_content`, `account`/`account_mut`, `restore_from`, panel height/width/follow accessors); panel window accessors (`panel_scroll_offset`, `panel_lines`, `panel_lines_below`) keyed off a caller-supplied `Instant`; tree-structure accessors (`rows`, `collapsed`/`is_collapsed`/`can_collapse`, `pacted_only`/`toggle_pacted_only`, `show_files`/`toggle_files`, `counts`, `is_empty`, `selected`, `selected_row`); scrolling/viewport methods (`scroll_offset`, `viewport_height`, `set_viewport_height`, `mouse_captured`/`set_mouse_captured`, `focus`/`toggle_focus`/`set_focus`); a family of movement methods (`select_previous/next`, `select_page_up/down`, `select_first/last`) funneling through a private `movement` dispatcher, plus pointer-driven equivalents (`select_row`, `select_next_by`/`select_previous_by`, `scroll_panel_down`/`up`) that ignore focus and never touch the footer message; the private `reflow` method rebuilding drawn `rows` from `all_rows` by applying the file filter, pacted-only filter, and collapsed-set filter in order, then re-anchoring selection by path; small helpers `moved`, `forget_last_keystroke`, `label_for`; and higher-level command methods returning `Option` outcomes — `toggle_collapsed`, `toggle_pact`, `refresh`, `scope_target`, `view_target` — each with specific refusal rules and wording for files, unpacted/fresh/ignored directories. `set_subtree_state` is the single point mutating node states across both row lists and the `counts` tally, respecting that ignored directories never move into a pacted state. `insert_file_row` splices in a new file/document row mid-run without a full reload, adjusting selection/scroll and positioning it in sort order among siblings.

**Free functions** following the impl block include `file_row_position`; `reseat_on` (rebuilds an `App` against a freshly reloaded `Tree` while preserving all view state, explicitly destructuring fields to force compile errors on new-field additions); `walk_of` (flattens a `Tree` into `all_rows`); `node_rows`, `paint_subtree`/`moves_with_subtree`/`in_subtree`, `drawn_rows`, `pacted_rows`, `index_for`, `scroll_offset_for` (pure minimum-movement scroll rule), `panel_offset_for` (pure follow-vs-parked panel scroll rule); a long series of pure message-formatting functions (`left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `unpacted_scope_message`, `directory_view_message`, `undocumented_view_message`, `cut_at_cap_message`, `no_document_message`, `summarising_message`, `already_running_message`, `file_row_message`, `ignored_row_message`); and `count_mut`, mapping a `NodeState` to its `StateCounts` field.

**Test module.** The remainder of the file (more than half of it) is `#[cfg(test)] mod tests`, containing extensive helper/fixture functions (`paths_and_depths`, `node_paths`, `states`, `shape`, various `*_fixture` functions encoding expected drawn-row orders, `app_selecting`, `select`, `selection_is_on_screen`, `window_is_in_range`, `tally`, `many_rows`, `scrolled_to`, `drawn`, `rows_with_one_kept_out`, `tree_with_one_scoped_directory`, `at`, `panel_text`, `app_pacting`, `account_window`, `document_window`, `document_text`, `record_lines`, `rewritten_lines`, `document_lines`, `a_long_line`, `tree_listing`, `list_file`, `app_with_files`, `as_the_document`, `tree_without_the_tui_crate`, `selected_path`, and a `MOVEMENTS` key-to-method-pointer table) alongside constants (`MANY`, `WINDOW`, `PANEL`, `NARROW`, `NOTCH`).

The tests systematically exercise: flattening a `Tree` into rows (order, depth, state, document association, ignored flag, scope, child counts); `StateCounts` mirroring and stability; `Chrome`/header/`Sigils` construction and wording; selection movement (no wrap, no-op on empty); `scroll_offset_for` under many window/tree-size combinations, and `App`'s page/first/last/viewport methods; pacting/un-pacting behavior and propagation, including refusal wording for files, unpacted, fresh, and `.warlockignore`-excluded rows; `set_subtree_state` semantics; message clearing/setting rules; `refresh()`/`scope_target()` refusal and targeting logic; pact-in-flight progress state (`pact_line`, summarising, refused, in-flight-covers checks); collapsing/expanding (byte-for-byte hide/restore, selection landing, survival through rebuild, no-ops on leaves); the pacted-only filter (ancestor preservation, selection relocation, interaction with collapsing); the show-files toggle (file row insertion/removal, refusal to pact a file or a document row, tally stability); directory document rows (synthetic rows under documented directories, field-sharing with file-toggle view); viewport/selection stability across all these toggles; focus behavior (movement gated to tree focus, other actions focus-independent); the two-card panel model (account and document cards independently scrollable/followable, `swap_card`, refusal when nothing/no document shown); document viewing (top-of-file display, cut-at-cap message, word-wrapping and re-wrapping on width change, wrapped-row scroll counting, account view never wrapping); view-target logic for files vs. documented/undocumented directories; wheel/mouse-style scrolling methods matching stepped equivalents while ignoring focus and leaving the message untouched; re-seating onto a newly loaded tree (carrying over cards, collapsed set, view flags, selection relocation to nearest surviving ancestor, no-op on an unchanged tree); and, at length, `insert_file_row`'s full behavioral contract — idempotence on duplicates, no-op when the parent directory has no row, tally stability, survival through view rebuilds, immediate visibility of newly documented directories under the default files-hidden view, structural (not name-based) row classification, respect for collapsed state and the pacted-only filter, and stability of selection index and scroll window when a row is inserted above or below the current position. The test module, and the file, end here.
