This is the complete contents of `app.rs` — a single self-contained Rust source file (not split into multiple parts, though presented as part 1 of 1) making up the front-end state layer of Warlock's TUI. It has three broad sections: an extensive module-level doc comment, the implementation code, and a large `#[cfg(test)] mod tests` block.

**Module doc comment**: Explains the design rationale for this file. The core idea is that the engine's tree walk is flattened into a list of `Row`s for screen display, with the app remembering which rows are collapsed (by path, not index, so state survives tree reloads), whether the view is narrowed to "pacted-only" content, and whether files are shown alongside directories. It also covers scroll/viewport state, a "focus" concept (tree/panel/composer), pointer-driven selection methods separate from keyboard ones, an in-flight pact/refresh run tracker, an `Account` of what a run did, and a three-card panel (account, thread/conversation, document) each with its own scroll window and "follow newest line" behavior.

**Types defined**: `Row` (a flattened tree/file row with path, document, state, children count, file/document/ignored flags, and scope), `PactToggle`, `Run` (Pact vs Refresh), `InFlight`, `RunHeader`, `Summarising`, `Focus` (Tree/Panel/Composer enum with cycling logic), `Sigils` (Nothing/Held/Unknown — what machine-local sigils are held, for scope display), `Chrome` (header line + sigils, resolved once per session, not app state), `App` (the main struct: all_rows, rows, collapsible set, counts, selected, scroll_offset, viewpoint, status, panel), `Viewpoint` (collapsed set, pacted_only, show_files, viewport_height, focus), `Status` (message, in_flight, summarising, pact_refused, mouse_captured), `Panel` (three `Card<T>` slots: account/thread/document, showing enum, mode, height/width), `Showing` enum, `Mode` (Chat/Brief), `Card<T>` generic struct with `Shown` trait implemented for `Account`, `Thread`, and `Vec<Line>`.

**`App` impl**: Constructors (`from_tree`, `from_rows`, `with_collapsed`, `with_counts`), message/pact-in-flight/summarising setters and the `pact_line`/`run_header` accessors, panel-card lifecycle methods (`start_account`, `write_run`, `show_document`, `refill_document`, `start_turn`, `note`, `record_turn`, `answer_turn`, `end_turn`, `thread`, `swap_card`/`next_card`/`stops_on`, `has_account`/`has_thread`/`has_document`/`has_panel_content`, `mode`/`set_mode`), `restore_from` for rollback, panel height/width/scroll accessors, tree row accessors (`rows`, `collapsed`, `is_collapsed`, `can_collapse`), `pacted_only`/`toggle_pacted_only`, `show_files`/`toggle_files`, selection/scroll accessors, focus methods (`focus`, `composer_showable`, `toggle_focus`, `set_focus`, `rescue_focus`), movement methods (`select_previous/next/page_up/page_down/first/last`, `select_row`, `select_next_by`/`select_previous_by`, `scroll_panel_down/up`, private `movement`/`scroll_panel_to`/`page`/`panel_page`/`rescroll`/`reflow`/`moved`/`forget_last_keystroke`/`label_for`), and the core mutation methods `toggle_collapsed`, `toggle_pact`, `refresh`, `scope_target`, `view_target`, `set_subtree_state`, `insert_file_row`.

**Free functions**: `file_row_position`, `reseat_on` (rebuilds an `App` from a fresh `Tree` while preserving view state — selection by path, collapsed set, filters, window, panel), `walk_of`, `node_rows`, `paint_subtree`, `moves_with_subtree`, `in_subtree`, `drawn_rows`, `pacted_rows`, `index_for`, `scroll_offset_for` (pure tree-scroll math), `panel_offset_for` (pure panel-scroll math), plus many small message-wording functions (`left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `unpacted_scope_message`, `directory_view_message`, `undocumented_view_message`, `cut_at_cap_message`, `no_document_message`, `summarising_message`, `already_running_message`, `file_row_message`, `ignored_row_message`), and `count_mut`.
