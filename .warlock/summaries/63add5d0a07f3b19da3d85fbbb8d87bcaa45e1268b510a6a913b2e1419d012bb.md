This is the entirety of `pact.rs`, one crate module covering the full pacting subsystem: turning a directory (or a whole subtree) into a `WARLOCK.md`, and the accompanying manifest bookkeeping.

**Module-level docs** (extensive) frame three layered operations — `pact_directory` (one directory, five steps: gather, describe oversized content, fit to budget, one agent pass, write the file), `pact_subtree` (children-first walk over a directory plus manifest hashing/granting), and `refresh_subtree` (same machinery restricted to directories `decide_state` calls stale). They explain the two-phase write-then-hash-and-grant design, cancellation semantics via `Observer`/`Pacting`, `.warlockignore` handling, the verbatim-write contract, and the scope/sigil boundary model (scopes live only on manifest entries; only `unpact_subtree` can drop one).

**Constants**: `MANIFEST_DIR` (`.warlock`), `DOCUMENT_FILE` (`WARLOCK.md`), `MINIMUM_DOCUMENT_BYTES` (200, public), `PROMPT` (the fixed instruction text sent to the model, private), `STAMP` (private, the `<!-- warlock -->` preamble every document gets).

**Public functions**: `pact_subtree`, `refresh_subtree`, `pact_directory`, `unpact_subtree`, `closed_scopes_at_or_below`, `view_file`.

**Private/crate-private helpers**: `is_fresh`, `describe_and_grant`, `rewrite`, `at_or_below`, `pact_directory_watched`, `stamped`, `pactable_directories` (crate-private), `read_capped`.

**Key types**: `Described` (private struct: `outcomes: BTreeMap<String, Outcome>`, `failures: Vec<Failure>`, `problems: Vec<Problem>`), `Outcome` (private, with methods `apply` and `into_entry`), `Grant` (private: `hash`, `at`), `Observer` trait (methods `starting` — required, returns `Pacting`; `summarising`, `requesting`, `documented` — all with no-op defaults), `Pacting` enum (`Continue`/`Stop`), `Unwatched` unit struct implementing `Observer`, `PactedSubtree` (public: fields `manifest`, `failures`, `problems`), `Pacted` (public: `document`, `problems`), `Viewed` (public: `text`, `cut`), `Unviewable` enum (public, non-exhaustive: `Unreadable{path,source}`, `NotText{path,source}`, plus method `path()`), `Refusal` enum (public, non-exhaustive: `Agent{source}`, `TooShort{bytes}`), `Error` enum (public, non-exhaustive: `Walk`, `Path`, `Refused`, `Write`, plus method `directory()`), `Failure` enum (public, non-exhaustive: `Document`, `Record`, `Hash`, plus method `directory()`).

All these types implement `fmt::Display` and `std::error::Error` where relevant (`Unviewable`, `Refusal`, `Error`, `Failure`).

Imports pull in `ignore::WalkBuilder`, and from sibling modules: `fitting` (`Fitted`, `PER_FILE_BYTE_CAP`, `Problem`, `byte_count`, `fit`), `ignores`, `manifest` (`ROOT_MODULE`, `temp_file_name`, `write_and_sync`), `scope::valid_scope`, and crate root items (`Agent`, `Manifest`, `NodeState`, `PactEntry`, `agent`, `decide_state`, `hash`, `manifest`, `now_rfc3339`, `scope_opens_to`, `subtree_hash`, `to_manifest_path`).

The file ends with a very large `#[cfg(test)] mod tests` block containing dozens of unit tests (fakes `Canned`, `Fails`, `Counting`, `FailsFor`, `FailsEveryMap`, `Watching`, `Overheard`/`Overhearing`, `Weighing`; helper functions like `document`, `written`, `write`, `filler`, `share`, `fat_directory`, `repository`, `project`, `refreshable`, `pacted`, `scoped`, `with_scopes`, etc.) covering: verbatim writing and atomicity, the summary/fitting ladder, over-cap and chunk-ceiling behavior, subtree ordering, cancellation, failure/partial-grant propagation, scope preservation across pact/refresh/cancel/unpact, exact manifest TOML byte output, and `view_file`'s cap/cut/UTF-8 behavior.
