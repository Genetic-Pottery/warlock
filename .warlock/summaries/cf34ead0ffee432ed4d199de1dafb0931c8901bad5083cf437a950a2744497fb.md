This is the complete, single-part contents of `thread.rs` — the module implementing the "thread" (conversation) card of a panel, distinct from the ledger/account card and the file card. It opens with extensive module-level doc comments explaining the conceptual model, followed by the actual Rust implementation and its test module.

**Module doc comments** describe: the conversation is an ordered list of entries — mostly turns (one per typed message, holding the message, observed model work, and the answer) and notes (single unclocked lines warlock says itself). It explains the clock rules (built on `Log`, shared with the account), the `waiting` placeholder, what work lines contain (tool calls, `thinking`, `writing`) and what is excluded (tool results, model reasoning, streamed fragments). It distinguishes turns from pact/refresh runs (which belong to the account card, not here), describes notes and their unclocked nature (drawn as `Line::Note`), discusses a future "synthesized instruction" concept (referencing `Thread::ask`), and explains two deliberate differences from the account: cost is heard and discarded (see `Thread::record`), and a turn ends in one line via `Ending` rather than the three-way `Outcome` used for pacts.

**Public enum `Ending`** (public, `#[derive(Debug, Clone, PartialEq, Eq)]`): variants `Cancelled`, `NoModel { program: String }`, `Failed { code: Option<i32>, stderr: String }`, `TimedOut { after: Duration }`, `NothingSaid`, `Broke { reason: String }`. Has public method `line(&self) -> String` (documented as `#[must_use]`, with a doctest using `warlock_tui::Ending`) producing the one-line description for each variant.

**Public function `ending_for(error: &agent::Error) -> Ending`** (`#[must_use]`) — maps `agent::Error` variants (`NotFound`, `Failed`, `TimedOut`, `EmptyOutput`, and a catch-all `other`) to `Ending` variants, with `Broke` as the catch-all for non-exhaustive/unknown errors.

**Public struct `Turn`** (`#[derive(Debug, Clone, PartialEq, Eq)]`) with private fields: `message: String`, `log: Log`, `answer: Option<String>`, `ending: Option<Ending>`. Public methods: `message(&self) -> &str`, `answer(&self) -> Option<&str>`, `ending(&self) -> Option<&Ending>` (const), `started(&self) -> Instant` (const), `is_closed(&self) -> bool` (const). Private methods: `line_count(&self) -> usize`, `rows(&self, now: Instant) -> impl Iterator<Item = Line> + '_`, `freeze(&mut self, at: Instant)`, `live(&mut self) -> Option<&mut Self>`, `word(&mut self, ending: &Ending, at: Instant)`.

**Private enum `Entry`** with variants `Turn(Turn)` and `Note { text: String, at: Instant }`. Private methods: `at(&self) -> Instant` (const), `line_count(&self) -> usize`, `rows(&self, now: Instant) -> Box<dyn Iterator<Item = Line> + '_>`, `turn(&self) -> Option<&Turn>` (const), `turn_mut(&mut self) -> Option<&mut Turn>` (const).

**Public struct `Thread`** (`#[derive(Debug, Clone, Default, PartialEq, Eq)]`) with private field `entries: Vec<Entry>`, and a doctest referencing `warlock_tui::{Activity, Line, Thread}`. Public methods: `new() -> Self` (const, `#[must_use]`), `ask(&mut self, message: impl Into<String>, at: Instant)`, `note(&mut self, text: impl Into<String>, at: Instant)`, `record(&mut self, activity: &Activity, at: Instant)`, `answer(&mut self, answer: impl Into<String>, at: Instant)`, `end(&mut self, ending: &Ending, at: Instant)`, `turns(&self) -> Vec<&Turn>` (`#[must_use]`), `is_empty(&self) -> bool` (`#[must_use]`), `started(&self) -> Option<Instant>` (`#[must_use]`), `in_flight(&self) -> Option<&Turn>` (`#[must_use]`), `line_count(&self) -> usize` (`#[must_use]`), `lines(&self, now: Instant) -> Vec<Line>` (`#[must_use]`), `window(&self, offset: usize, height: usize, now: Instant) -> Vec<Line>` (`#[must_use]`). Private methods: `last_turn(&self) -> Option<&Turn>`, `last_turn_mut(&mut self) -> Option<&mut Turn>`, `freeze_last(&mut self, at: Instant)`, `live(&mut self) -> Option<&mut Turn>`.

**Private free functions**: `broken(text: &str) -> impl Iterator<Item = &str>` (splits text into display rows, guaranteeing at least one empty row for empty text) and `one_line(text: &str) -> String` (collapses whitespace runs into single spaces, used for flattening notes and stderr).

**Imports**: `std::time::{Duration, Instant}`; `warlock_engine::agent`; from `crate::account`: `Line`, `Log`, `THINKING`, `WRITING`, `tool_line`; from `crate::claude`: `Activity`.

**Test module** (`#[cfg(test)] mod tests`) imports `warlock_engine::agent`, `super::{Ending, Thread, Turn, ending_for}`, `crate::account::{Account, Line, Outcome}`, `crate::claude::Activity`. Defines helper functions `at(base, seconds) -> Instant`, `tool(name, detail) -> Activity`, `said(thread, now) -> Vec<String>`, `work(thread, now) -> Vec<String>`, then numerous `#[test]` functions covering: empty conversation, full turn lifecycle (question/work/answer), the `waiting` placeholder, live-clock ticking and freezing on answer, per-turn clock reset, coalescing repeated thinking into one line, tool without detail, cost being heard/discarded (including cross-checking against `Account`'s cost display), no tool-result/model-prose leakage into work lines, answers kept whole/unwrapped, cancellation behavior, all `Ending` variants producing exactly one line each, empty-answer treated as `NothingSaid`, first-ending-wins semantics, nothing filed before first question, message with embedded newlines, `window` behavior, runs being entirely separate from the account, notes interleaving correctly among turns, notes as single unclocked non-turn rows, notes not affecting turn state, and `ending_for` mapping each `agent::Error` variant (including an unlisted `Io` variant mapping to `Broke`).
