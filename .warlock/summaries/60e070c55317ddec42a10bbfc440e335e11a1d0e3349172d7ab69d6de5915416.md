This is `app.rs` of Warlock's TUI front end — the entire file, containing the front end's core state module plus (at the end) a very large `#[cfg(test)]` test module.

**Module-level doc comment**: explains the design philosophy — the app flattens the engine's tree walk into `Row`s for screen display, keeps the whole walk (`all_rows`) separate from the drawn subset (`rows`) so collapsing/filtering/file-toggling are reversible without re-walking the tree; tracks collapsed nodes by path (not index) so they survive reloads; supports a pacted-only filter and a show-files toggle, both pure view filters; tracks scroll offset via a pure function; tracks a footer message that clears on next keystroke; tracks `Focus` (tree/panel/composer) as testable view state; supports pointer-driven selection distinct from key-driven; tracks an in-flight pact/refresh run and a summarizing sub-pass; and a `Panel` holding three "cards" (account, thread, document) each with independent scroll/follow state.

**Key types defined:**
- `Row`: one flattened tree line — depth, path, document, state, children count, file flag, document-row flag, ignored flag, scope — with builder methods (`new`, `file`, `with_child_count`, `with_ignored`, `with_document_row`, `with_scope`) and query methods (`has_children`, `is_file`, `is_document`, `is_ignored`).
- `PactToggle`: result of toggling a pact (path + pacted bool).
- `Run` enum (Pact/Refresh) and `InFlight` struct (private): tracks a running pact/refresh's directory, position, high-water "reached" mark, total, and kind.
- `RunHeader`: public snapshot struct for panel header display (run kind, directory label, position, total).
- `Summarising` (private): tracks a chunked-summarization sub-pass (file, part, parts).
- `Focus` enum (Tree/Panel/Composer) with `next()`, `drives_the_tree()`, `drives_the_panel()`.
- `Sigils` enum (Nothing/Held(Vec<String>)/Unknown) — what sigils this machine holds, with `held()` constructor, `as_slice()`, `line()` for footer wording.
- `Chrome`: header line state (repo-relative header text + `Sigils`), built via `Chrome::of` and `with_sigils`.
- `App`: the main struct — `all_rows`, `rows`, `collapsible`, `counts`, `selected`, `scroll_offset`, `viewpoint` (Viewpoint), `status` (Status), `panel` (Panel).
- `Viewpoint` (private): collapsed set, pacted_only, show_files, viewport_height, focus.
- `Status` (private): message, in_flight, summarising, pact_refused, mouse_captured.
- `Panel` (private): three `Card<T>` instances (account, thread, document), `showing` (Showing enum), height, width.
- `Showing` enum (Account/Thread/Document) with cycling `next()`.
- `Card<T>`: generic holder with offset/follows window state, methods `place`, `accrue`, `line_count`, `scroll_offset`, `window`, `lines_below`, `scroll_to`.
- `Shown` trait implemented for `Account`, `Thread`, `Vec<Line>` (document) — defines line counting/windowing for panel rendering.
- Helper function `rows_of` for wrapping.

**`App` impl** (large): constructors (`from_tree`, `from_rows`, `with_collapsed`, `with_counts`); message/status setters (`set_message`, `set_pact_in_flight`, `set_run_in_flight`, `set_pact_summarising`, `clear_pact_in_flight`, `set_pact_refused`); queries (`is_pacting`, `is_in_flight`, `in_flight_covers`, `pact_line`, `run_header`); panel/account/thread/document lifecycle methods (`start_account`, `write_run`, `show_document`, `refill_document`, `start_turn`, `record_turn`, `answer_turn`, `end_turn`, `thread`, `swap_card`, `next_card`, `stops_on`, `has_account`/`has_thread`/`has_document`/`has_panel_content`, `showing_thread`, `account`/`account_mut`, `restore_from`); panel sizing/scrolling (`set_panel_height/width`, `panel_follows`, `panel_scroll_offset`, `panel_lines`, `panel_lines_below`); tree accessors (`rows`, `collapsed`, `is_collapsed`, `can_collapse`, `pacted_only`, `toggle_pacted_only`, `show_files`, `toggle_files`, `counts`, `is_empty`, `selected`, `selected_row`, `scroll_offset`, `viewport_height`, `set_viewport_height`); mouse/focus (`mouse_captured`, `set_mouse_captured`, `focus`, `composer_showable`, `toggle_focus`, `set_focus`, `rescue_focus`); movement methods (`select_previous/next/page_up/page_down/first/last`, `select_row`, `select_next_by`/`select_previous_by`, `scroll_panel_down/up`, private `movement`, `scroll_panel_to`, `page`, `panel_page`, `rescroll`, `reflow`, `moved`, `forget_last_keystroke`, `label_for`); action methods (`toggle_collapsed`, `toggle_pact`, `refresh`, `scope_target`, `view_target`, `set_subtree_state`, `insert_file_row`).

**Free functions**: `file_row_position`, `reseat_on` (rebuilds an App on a freshly-reloaded Tree while preserving view state), `walk_of`, `node_rows`, `paint_subtree`, `moves_with_subtree`, `in_subtree`, `drawn_rows`, `pacted_rows`, `index_for`, `scroll_offset_for` (pure scrolling math), `panel_offset_for` (pure panel-window math), and numerous message-wording functions (`left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `unpacted_scope_message`, `directory_view_message`, `undocumented_view_message`, `cut_at_cap_message`, `no_document_message`, `summarising_message`, `already_running_message`, `file_row_message`, `ignored_row_message`), plus `count_mut`.

**Test module** (very large, the bulk of the file): hundreds of unit tests covering flattening, scrolling math, collapse/expand, pacted-only filter, show-files toggle, pact/unpact/refresh/scope-target/view-target refusals and messages, subtree state painting, ignored/.warlockignore handling, scope carrying, in-flight pact/refresh progress lines and headers, summarizing sub-pass wording, panel/account/thread/document card independence and window/follow behavior, focus cycling and composer visibility rules, swap-card cycling and refusal, pointer-driven selection (`select_row`, `select_next_by`/`select_previous_by`, wheel-over-tree vs wheel-over-panel), reseat-on-reload behavior (carrying selection/collapsed/view flags/panel state across tree rebuilds), and `insert_file_row` splicing behavior (ordering, ignored/scope inheritance, tally invariance, selection/scroll adjustment). Numerous small helper functions/fixtures support these tests (`three_rows`, `rooted_rows`, `tally`, `scrolled_to`, `drawn`, `app_selecting`, `app_pacting`, `ask_and_answer`, `run_a_pact`, etc.).
