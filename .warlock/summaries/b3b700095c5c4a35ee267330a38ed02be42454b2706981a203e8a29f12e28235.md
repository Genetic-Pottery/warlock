This file defines the panel module: the right-hand pane holding three "cards" (account, thread, document) plus the window logic a renderer draws from.

Core types:
- `Panel` (pub(crate) struct, derives Debug/Clone/Default/PartialEq): fields `account: Card<Account>`, `thread: Card<Thread>`, `document: Card<Vec<Line>>`, `showing: Showing`, `mode: Mode`, `height: usize`, `width: usize`.
- `Showing` (pub(crate) enum, Copy/Default/Eq/Hash): variants `Account`, `Thread` (default), `Document`. Has a private const method `next(self) -> Self` cycling Thread→Account→Document→Thread.
- `Mode` (pub enum, Copy/Default/Eq/Hash): variants `Chat` (default) and `Brief`.
- `Card<T>` (private struct): fields `held: Option<T>`, `offset: usize`, `follows: bool`. Has a hand-written `Default` impl (not derived, since `T` like `Account` has no default). Methods (all private, `impl<T: Shown> Card<T>`): `place(&mut self, held: T, follows: bool)`, `accrue(&mut self) -> &mut T` (requires `T: Default`), `line_count(&self, width: usize) -> usize`, `scroll_offset(&self, height, width) -> usize`, `window(&self, height, width, now: Instant) -> Vec<Line>`, `lines_below(&self, height, width) -> usize`, `scroll_to(&mut self, offset, height, width)`.
- `Shown` (private trait): `line_count(&self, width) -> usize`, `window(&self, offset, height, width, now: Instant) -> Vec<Line>`. Implemented for `Account`, `Thread`, and `Vec<Line>`.
- Free function `rows_of(line: &Line, width: usize) -> Vec<Line>` — private helper wrapping `wrap_rows` (imported as `crate::wrap::rows`).
- Free function `pub(crate) fn panel_offset_for(lines: usize, viewport: usize, offset: usize, following: bool) -> usize` — pure scrolling arithmetic, deliberately independent of `App`.

`Panel` methods (impl block, mix of pub(crate)):
- `scroll_offset(&self) -> usize`, `window(&self, now: Instant) -> Vec<Line>`, `lines_below(&self) -> usize`, `scroll_to(&mut self, offset: usize)` — dispatch on `showing` across the three cards.
