This part is the complete source of a module governing a chat conversation's state machine, its turn lifecycle, and the `/brief`, `/chat`, and `/write` commands, along with an extensive embedded test suite.

The module opens with a long doc comment explaining design rationale: `Chat` bundles the register (held on `App`, not here), the draft field, and the turn, treating a "turn" as a smaller analogue of a pact/run (`pacting`), following the same spawn/start/run/apply four-part shape via `spawn_turn`, `start_turn`, `run_turn`, and `apply_turn`. It explains that a turn touches a repository root now (for `/brief` and `/write`), that the composer field is muted only while a turn is in flight (derived state via `Chat::answering`), and that every turn failure funnels into exactly one `Ending` value so no error ever propagates out of the event loop. It also discusses `CancelGuard` reuse from `pacting`.

Imports: standard library (`path`, `mpsc`, `thread`, `Instant`), `warlock_engine` items (`DEFAULT_BRIEF_DIRECTORY`, `Manifest`, `briefs`, `load_briefs`), and many `warlock_tui` items (`Activities`, `Activity`, `App`, `BRIEF_EFFORT`, `BRIEF_MODEL`, `Cancel`, `ChatAgent`, `Composed`, `Composer`, `Converses`, `Edited`, `Ending`, `Focus`, `Mode`, `ScopePrompt`, `Submitted`, `TemplateError`, `WRITE_INSTRUCTION`, `brief_instruction`, `brief_template`, `ending_for`, `submitted_for`), plus crate-local `error::one_line`, `pacting::CancelGuard`, `writing::{write_edit, write_opened}`.

Constants (all private, `const`): `TURN_LOST` (message for a worker that panicked), `BRIEF_COMMAND` (`"/brief"`), `CHAT_COMMAND` (`"/chat"`), `WRITE_COMMAND` (`"/write"`), `BRIEF_NOTE`, `CHAT_NOTE`, `ALREADY_CHATTING`, `NOT_BRIEFING`.

Private free functions: `unreadable_template(error: &TemplateError) -> String`, `brief_asking(root: &Path) -> Result<String, TemplateError>`, `unreadable_briefs(error: &briefs::Error) -> String`, `brief_reading(root: &Path) -> Result<(String, String), String>` (returns instruction and directory, reads template then briefs.toml, stops at first failure).

Public-to-crate (`pub(crate)`) struct `Chat<C>` with fields: `agent: C` (private), `turn: Option<Chatting>` (private), `root: PathBuf` (private), `composer: Composer` (private), `directory: String` (private), `prompt: ScopePrompt` (private). Impl block `impl Chat<ChatAgent>` with `pub(crate) fn new(root)`. Impl block `impl<C: Converses> Chat<C>` with methods: `with_agent` (pub(crate)), `composer()` (pub(crate) const, returns `&Composer`), `write_prompt()` (pub(crate) const), `directory()` (pub(crate), `#[cfg(test)]`), `answering()` (pub(crate) const bool), `ask(app, message, now)` (pub(crate)), `say(app, shown, sent, asked, now)` (pub(crate)), `settle_field()` (private), `stop()` (pub(crate)), `compose(app, outcome: Composed, now)` (pub(crate), the large method implementing Typing/Leave/Submit and the three commands), `keep_up(app, now)` (pub(crate)), `write(app, manifest, edited, now)` (pub(crate), calls `write_edit`).

Struct `Chatting` (pub(crate)) with fields `events: Receiver<TurnEvent>`, `cancel: CancelGuard`, `asked: Asked` (all pub(crate)). Enum `Asked` (pub(crate), derives Debug/Clone/Copy/PartialEq/Eq) with variants `Answer` and `Document`. Enum `TurnEvent` (pub(crate), derives Debug) with variants `Doing(Activity)` and `Finished(Result<String, Ending>)`.

Private free functions: `activity_port(events: &Sender<TurnEvent>) -> Activities`, `wired<C: Converses>(agent, cancel, events) -> C`, `asking<C: Converses>(agent, mode: Mode) -> C` (chooses `agent.raised(BRIEF_MODEL, BRIEF_EFFORT)` for Brief mode or clone for Chat mode).

Public-to-crate functions: `spawn_turn<C: Converses>(message, agent, cancel) -> Receiver<TurnEvent>`, `start_turn<C: Converses>(message, agent, asked: Asked) -> Chatting`. Private `run_turn<C: Converses>(message, agent, cancel, events)` (worker body). Public-to-crate `apply_turn(chat: &mut Option<Chatting>, app: &mut App, now: Instant) -> Option<String>` (drains channel, returns document only for `Asked::Document` turns). Private `end(app, ending, now)`.

The remainder (`#[cfg(test)] mod tests`) is a very large test suite, including helper functions (`at`, `asking`, `chatting`, `writing`, `turn_for`, `drain`, `rows`, `said`, `clocked`, `words`, `value_of`) and numerous `#[test]` functions covering work-line streaming, answers, cancellation, mode switching (`asking` function correctness), write-turn document handoff, and failure endings. Inside it, a `#[cfg(unix)] mod unix` submodule tests real subprocess behavior via `/bin/sh` stand-ins (constants `AT_MOST`, `NO_REPOSITORY`, `TEARDOWN_TICK`, `NOT_A_PROGRAM`, `TURN`, `ANSWER`; helper functions `reported`, `stand_in`, `printing`, `turned`, `doings`, `ended`, `ending`, `scratch`, `clean_up`, `size`, `settled`, `settle`, `wait_for`), with tests for answering, missing binary, non-zero exit, empty output, timeout, cancellation (both pre-start and mid-flight), process killing on drop, full round-trip through the card, `Chat::stop`, synthesized `/brief` turn instruction delivery, failure recovery, and `/write` turn success/failure paths.

Also nested `mod submitting` with its own constants (`NOT_A_PROGRAM`, `NO_REPOSITORY`) and helpers (`conversation`, `conversation_in`, `a_root`, `write_template`, `write_briefs`, `submit`, `submit_into`, `note`, `asked`, `rows`, `turns`, `proposal`) testing field muting, `/write` inside/outside brief mode, `/brief` note-and-turn behavior, template/briefs.toml reading including unreadable-file refusals (`unreadable_template`/`unreadable_briefs` paths), directory settling and re-reading, `/chat` entering/leaving mode, ordering guarantees (no rows cleared/reordered), refusal-only handling, and plain message submission.
