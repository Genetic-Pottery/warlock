This is the entirety (part 1 of 1) of `app.rs`, a Rust module implementing the front-end application state for a TUI tool called "Warlock" (a freshness ledger over a codebase's own documentation). The file has an extensive module-level doc comment and then code, organized as follows:

**Core data types:**

- `Row` (public struct): the flattened representation of one line of the tree — fields `depth`, `path`, `document`, `state` (`NodeState`), `children`, `file`, `document_row`, `ignored`, `scope`. Constructors `Row::new` and `Row::file` (public), and builder methods `with_child_count`, `with_ignored`, `with_document_row`, `with_scope` (all public). Accessor methods `has_children`, `is_file`, `is_document`, `is_ignored` (public).
- `PactToggle` (public struct): fields `path`, `pacted` — describes what a pact toggle requested.
- `Run` (public enum): `Pact`, `Refresh` — kind of run in flight.
- `InFlight` (private struct): fields `path`, `position`, `reached`, `total`, `run` — tracks a running pact/refresh.
- `RunHeader` (public struct): fields `run`, `directory`, `position`, `total`, with public accessor methods `run()`, `directory()`, `position()`, `total()`.
- `Summarising` (private struct): fields `path`, `part`, `parts` — tracks a chunked summarization pass.
- `Focus` (public enum): `Tree` (default), `Panel`, `Composer` — which pane keys drive. Methods `next()`, `drives_the_tree()`, `drives_the_panel()` (all public/const).
- `Sigils` (public enum): `Nothing` (default), `Held(Vec<String>)`, `Unknown` — what a machine holds re: scope sigils. Methods `held()`, `as_slice()`, `line()` (public).
- `Chrome` (public struct): fields `header`, `sigils` — the header line data, deliberately not part of `App`. Methods `Chrome::of()`, `with_sigils()`, `header()`, `sigils()` (public).
- `App` (public struct, the main type): fields `all_rows`, `rows`, `collapsible`, `counts`, `selected`, `scroll_offset`, `viewpoint` (`Viewpoint`), `status` (`Status`), `panel` (`Panel`).
- `Viewpoint` (private struct): fields `collapsed`, `pacted_only`, `show_files`, `viewport_height`, `focus`.
- `Status` (private struct): fields `message`, `in_flight`, `summarising`, `pact_refused`, `mouse_captured`.

**`App` impl** — a very large set of public methods covering: construction (`from_tree`, `from_rows`, `with_collapsed`, `with_counts`), messaging (`message`, `set_message`), pact-in-flight tracking (`set_pact_in_flight`, `set_run_in_flight`, `set_pact_summarising`, `clear_pact_in_flight`, `set_pact_refused`, `is_pacting`, `is_in_flight`, `in_flight_covers`, `pact_line`, `run_header`), panel/account/thread/document management (`start_account`, `write_run`, `show_document`, `refill_document`, `start_turn`, `note`, `record_turn`, `answer_turn`, `end_turn`, `thread`, `swap_card`, `has_account`, `has_thread`, `has_document`, `has_panel_content`, `showing_thread`, `mode`, `set_mode`, `account`, `account_mut`, `restore_from`, `panel_height`, `set_panel_height`, `panel_width`, `set_panel_width`, `panel_follows`, `panel_scroll_offset`, `panel_lines`, `panel_lines_below`), tree/row queries (`rows`, `collapsed`, `is_collapsed`, `can_collapse`, `pacted_only`, `toggle_pacted_only`, `show_files`, `toggle_files`, `counts`, `is_empty`, `selected`, `selected_row`, `scroll_offset`, `viewport_height`, `set_viewport_height`, `mouse_captured`, `set_mouse_captured`, `focus`, `composer_showable`, `toggle_focus`, `set_focus`, `rescue_focus` (private)), selection movement (`select_previous`, `select_next`, `select_page_up`, `select_page_down`, `select_first`, `select_last`, `select_row`, `select_next_by`, `select_previous_by`, `scroll_panel_down`, `scroll_panel_up`, `movement` (private), `scroll_panel_to` (private), `page`/`panel_page` (private), `rescroll` (private), `reflow` (private), `moved`/`forget_last_keystroke` (private)), labeling (`label_for`), and the key actions `toggle_collapsed`, `toggle_pact`, `refresh`, `scope_target`, `view_target`, `set_subtree_state`, `insert_file_row`.

**Free functions:** `file_row_position`, `reseat_on` (public — rebuilds an `App` view on a new `Tree`), `walk_of`, `node_rows`, `paint_subtree`, `moves_with_subtree`, `in_subtree`, `drawn_rows`, `pacted_rows`, `index_for`, `scroll_offset_for`, plus many private message-wording functions (`left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `unpacted_scope_message`, `directory_view_message`, `undocumented_view_message`, `cut_at_cap_message` (pub(crate)), `no_document_message`, `summarising_message`, `already_running_message`, `file_row_message`, `ignored_row_message`), and `count_mut` (private).

**`#[cfg(test)] mod tests`** — an extremely large test suite (hundreds of tests) covering nearly every method above, with numerous helper functions (`three_rows`, `rooted_rows`, `tally`, `many_rows`, `scrolled_to`, `drawn`, `paths_and_depths`, `node_paths`, `states`, `whole_fixture`, `pacted_fixture`, `whole_fixture_after_a_run`, `collapsed_over_crates`, `whole_fixture_with_files`, `app_selecting`, `app_with_files_selecting`, `select`, `rows_with_one_kept_out`, `tree_with_one_scoped_directory`, `panel_text`, `account_window`/`thread_window`/`document_window`, `document_text`, `app_pacting`, `at`, `ask_and_answer`, `run_a_pact`, `record_lines`, `tree_listing`/`list_file`, `app_with_files`, `as_the_document`, `selected_path`, `tree_without_the_tui_crate`, `window_is_in_range`, `selection_is_on_screen`, `document_lines`, `a_long_line`, `rewritten_lines`) and constants (`MANY`, `WINDOW`, `PANEL`, `NARROW`, `NOTCH`, `QUESTION`, `ANSWER`).

A reader of the whole file needs to know this module contains no rendering/terminal code itself — it is pure state/logic, imports from `warlock_engine`, `crate::account`, `crate::claude`, `crate::panel`, `crate::thread`, and is designed to be fully unit-testable without I/O.
