This is Rust source for a module concerned with fitting a directory's contents into a size-bounded request for a model pass, part of what appears to be the "warlock" documentation-freshness tool. The content consists of: an extensive module-level doc comment (`//!`) explaining the design, followed by `use` imports, then the actual implementation code, and finally a large `#[cfg(test)] mod tests` block.

The module doc explains the "fitting" process: given a directory and two byte caps (per-file and whole-request), producing an `agent::Request`. It describes a four-step "ladder": gather, describe over-cap files via summarization, fit the whole request to budget, and announce the weight. It documents the design principle that neither cap may fail a fit — files degrade from whole → summarized → name-and-size, never truncated.
