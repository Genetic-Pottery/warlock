This is the full source of the manifest module implementing `.warlock/pacts.toml`, the single, hand-editable TOML file recording which directories are pacted and what was granted to each. It opens with module-level doc comments explaining the design rationale: one manifest per repo, committed to git, human-editable as an escape hatch; an entry with no granted hash means "never judged" (absence is the whole representation, no sentinel); paths are stored relative to the manifest's directory with forward slashes for cross-platform, cross-clone byte identity; and a stored scope is preserved exactly as written, never validated or normalized by this module (validation lives elsewhere, in `validate_scope`).

Constants define the manifest's location (`.warlock/pacts.toml`), the sentinel spelling `"."` for the repository root as a stored path (`ROOT_MODULE`), and the schema version (`SCHEMA_VERSION = 1`), which is enforced strictly — any other version is rejected rather than guessed at.

The `Manifest` struct holds a `version` and an ordered `Vec<PactEntry>` (serialized as `[[pact]]` tables), with private fields to protect invariants. Its methods include: `new`/`with_entries`/`Default` constructors; accessors `version()`, `entries()`; `push`; `entry(module)` lookup by stored path; `to_toml_string`/`from_toml_str` for text conversion (with doc-tested examples); and `save`/`load` for atomic disk I/O rooted at a given repository root (not searched for). `save` writes to a temp file in the same directory then renames it, cleaning up on failure; `load` distinguishes a missing file (`Error::NotFound`) from a present-but-corrupt one, deliberately not conflating "never pacted" with "pacted nothing."

`PactEntry` represents one pacted module: private `module` and `document` path strings (manifest-relative, forward-slash form), an optional `scope` (person-owned, stored verbatim, never touched by run logic), and optional `granted_hash`/`granted_at` (absent together, meaning unjudged). Its API: `new` (normalizes caller paths via `to_manifest_path`), `with_grant`/`without_grant`, `with_scope`/`without_scope`, a crate-private `stored` constructor for already-normalized paths, a crate-private `overwrite_run_fields` that updates only module/document/grant while explicitly leaving `scope` untouched (documented as the mechanism ensuring scope survives across pact runs), and accessors `module()`, `document()`, `scope()`, `module_path(root)`, `document_path(root)`, `granted_hash()`, `granted_at()`, `is_judged()`.

Free functions: `to_manifest_path(root, path)` converts an absolute-or-relative path into stored form (erroring on paths outside root or non-UTF-8 components); `from_manifest_path(root, stored)` is its inverse; `manifest_path(root)` joins to the file location; `temp_file_name(target)` generates a unique hidden temp filename (process id + atomic counter) used both here and by the `pact` module for atomic writes, explained as deliberately dot-prefixed so ignore-walks and casual listings skip it; `write_and_sync` writes bytes and fsyncs before rename, explained as necessary to avoid a crash leaving an empty file.

A hand-rolled `Error` enum (`#[non_exhaustive]`) covers `NotFound`, `Io`, `Syntax`, `UnsupportedVersion`, `Entry` (with index and optional module name), `Serialize`, `PathOutsideRoot`, `NonUtf8Path`, with full `Display` and `std::error::Error` (`source`) implementations.

Internally, parsing goes through a two-stage `RawManifest` (version as raw `i64`, pact entries as raw `toml::Value`s) so that an unsupported version is rejected before entries are interpreted, and a malformed entry can be reported by index and, if readable, by its module string. A custom `deserialize_version` function also guards the derived `Deserialize` path so that even a direct `toml::from_str::<Manifest>` call can't bypass the version check.

The remainder (roughly half the content) is a `#[cfg(test)] mod tests` block with extensive unit tests covering: round-tripping judged/unjudged entries and presence/absence of grant keys; scope key omission and preservation, including byte-for-byte round-trips of both valid and deliberately invalid/odd scope strings (empty, malformed, non-ASCII, mixed case) to confirm no validation or normalization happens in this layer; backward compatibility with manifests written before scopes existed; that setting/clearing scope doesn't touch other fields; path normalization (absolute→relative, `.` handling, root-as-dot, forward slashes, cross-root identical serialization); rejection of paths outside root and non-UTF-8 paths (Unix-only test); rejection of an unrecognized future schema version before entries are read; naming of malformed entries by index/module; rejection of unknown keys per entry, including confirming the old `readme` key name is treated as an unknown key (not aliased) since the field was renamed to `document`; syntax-error handling for non-TOML text; `Display` text for every `Error` variant; `source()` chaining; atomic save behavior (directory creation, single file left behind, overwrite behavior, byte-identical output across two different roots); load/save round-trip fidelity including from hand-written files; distinguishing missing vs. corrupt manifests; and error naming for bad entries during load. Helper functions in the test module include `unjudged()`/`judged()` fixture builders, `a_de_error()` for constructing a `toml::de::Error` to test `Display`, `a_root()` for a temp directory, `warlock_dir_listing()`, and `hand_write()` to simulate manual edits.
