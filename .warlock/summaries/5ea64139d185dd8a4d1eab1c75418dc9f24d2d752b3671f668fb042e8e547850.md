This is the complete text of `main.rs`, the terminal front-end binary for warlock. It consists of an extensive module-level doc comment followed by implementation code and a large test module.

**Doc comment (top of file):** Explains the binary's architecture at length: it is the "thin, impure shell" around `warlock_tui`, owning terminal lifecycle, working directory, and the event loop. It describes how each concern is delegated to sibling modules (named as `input`, `pacting`, `chatting`, `scoping`, `viewing`, `editing`, `writing`, `session`, `terminal`, `error`), and walks through: terminal restoration guarantees on every exit path; how the pact key (`p`) and refresh key (`r`) run on worker threads via `Pact` and `Pact::press`/`Pact::keep_up`; how `reload_tree` re-reads the tree after runs, edits, or filesystem changes detected by `Watched`/`WatchPolicy`; how Esc cancels vs. `q`/Ctrl-C quits (via `Cancel`); mouse handling (`TerminalGuard`, `mouse_action`, `input::action_for`); the quit-confirmation flow (`QuitConfirm`, `press_for`); the composer/chat input (`Chat`, `App::focus`, `warlock_tui::compose_for`); the scope prompt (`s` key, `scoping` module); and the CLI subcommand behavior for `init`, `config`, `stale`, `fresh`, `check`, `unpact`, `pact`, `refresh`, `scope add`/`scope remove`, including exit status conventions (0, 1, 2, 3, 4, 130).

**Imports:** Brings in `std::io`, `std::path::PathBuf`, `std::process::ExitCode`, `std::time::{Duration, Instant}`, `clap::{Parser, Subcommand}`, crossterm/ratatui event and layout types, `warlock_engine` items (`Agent`, `Manifest`, `Written`, `write_claude_md`), and `warlock_tui` items (`App`, `Composer`, `Converses`, `Focus`, `QuitConfirm`, `Run`, `ScopePrompt`, `Wired`, `composer_on_screen`, `draw`, `panel_height`, `panel_width`, `tree_height`).

**Module declarations (all private, `mod`):** `boundary`, `chatting`, `check`, `config`, `descent`, `editing`, `edits`, `error`, `input`, `pacting`, `query`, `running`, `scoping`, `session`, `standing`, `stubs` (test-only, `#[cfg(test)]`), `terminal`, `viewing`, `writing`.

**Use statements** pull in specific items from these modules: `Chat` (chatting), `check` (check), `configure` (config), `edit_press` (editing), `scope_add`, `scope_remove`, `unpact` (edits), `Error` (error), `Action`, `MouseAction`, `Pressed`, `mouse_action`, `press_for` (input), `Pact`, `Reloaded` (pacting), `Listing`, `list` (query), `pact`, `refresh` (running), `scope_edit`, `scope_press` (scoping), `Scope`, `Watched`, `load_app`, `load_manifest`, `start_watching` (session), `FOR_CLAUDE_MD`, `Standing` (standing), `Screen`, `TerminalGuard`, `install_panic_hook` (terminal), `view_press` (viewing).

**Constants:**
- `POLL_INTERVAL: Duration` — public? (private, no `pub`) = 100ms, how long the loop waits for a keystroke each round.
- `CREATED: &str` (private) = `"created"`, printed by `warlock init` when a new `CLAUDE.md` was written.
- `UPDATED: &str` (private) = `"updated"`, printed when an existing one was re-spliced.
- `CANCELLED: u8` (private) = `130`, the exit status for an interrupted run (128 + SIGINT), used both by `status_for` mapping `Error::Cancelled` and by the handler in the `running` module.

**Types:**
- `Cli` (private struct, derives `Debug, Clone, PartialEq, Eq, Parser`) — top-level clap parser with a `command: Option<Command>` field.
- `Command` (private enum, derives `Debug, Clone, PartialEq, Eq, Subcommand`) — variants: `Init`, `Config`, `Stale { path: Option<PathBuf>, json: bool }`, `Fresh { path: Option<PathBuf>, json: bool }`, `Check { path: PathBuf, json: bool }`, `Unpact { path: PathBuf }`, `Pact { path: PathBuf }`, `Refresh { path: PathBuf }`, `Scope { command: ScopeCommand }`.
- `ScopeCommand` (private enum, same derives) — variants: `Add { path: PathBuf, scope: String }`, `Remove { path: PathBuf }`.
- `Session<S: Screen, P: Wired + Agent, C: Converses>` (private struct) — generic session holding `app: App`, `screen: S`, `scope: Scope`, `manifest: Manifest`, `pact: Pact<P>`, `chat: Chat<C>`, `confirm: QuitConfirm`, `prompt: ScopePrompt`, `document: Option<PathBuf>`, `mouse_captured: bool`, `watched: Watched`. Methods (all private, `fn`, non-`pub`): `size(&self) -> io::Result<Size>`, `draw(&mut self, size: Size) -> io::Result<()>`, `point(&mut self, mouse: MouseEvent, size: Size)`, `press(&mut self, key: KeyEvent, now: Instant) -> Result<bool, Error>`, `keep_up(&mut self)`.

**Functions (all private, module-level):**
- `main() -> ExitCode` — parses `Cli`, dispatches on `cli.command` to `run()` (default, installs panic hook first), `init()`, `configure()`, `list(Listing::Stale/Fresh, path, json)`, `check(path, json)`, `unpact(&path)`, `pact(&path)`, `refresh(&path)`, `scope_add(&path, &scope)`, `scope_remove(&path)`; prints `warlock: {error}` on failure; returns `ExitCode::from(status_for(&outcome))`.
- `status_for(outcome: &Result<(), Error>) -> u8` (declared `const fn`) — maps `Ok(())` to 0, `Error::ClosedScope{..}` to 3, `Error::Failures{..}` to 4, `Error::Cancelled` to `CANCELLED` (130), everything else to 1.
- `init() -> Result<(), Error>` — implements `warlock init`: builds `Standing::here(FOR_CLAUDE_MD)`, calls `write_claude_md`, wraps errors as `Error::ClaudeMd { source }`, prints whether it was `CREATED` or `UPDATED` using `Written::Created` match, checked via `written.path()`.
- `run() -> Result<(), Error>` — the main event loop: loads app/scope/tree via `load_app()`, loads `Manifest` via `load_manifest`, starts `Watched` via `start_watching`, builds a `Session` (with `TerminalGuard::enter()?`, `Pact::new()`, `Chat::new(root)`), then loops: measure size, draw, poll for events (`Event::Key`/`Event::Mouse`), calls `session.press`/`session.point`, calls `session.keep_up()`.
- `apply_mouse(app: &mut App, mouse: MouseEvent, size: Size, confirm: QuitConfirm, prompt: &ScopePrompt, path_prompt: &ScopePrompt, composer: &Composer)` — translates a `MouseAction` (from `mouse_action`) into calls on `App`: `select_next_by`, `select_previous_by`, `scroll_panel_down`, `scroll_panel_up`, `set_focus` + `select_row`, `set_focus` + `toggle_collapsed`, `set_focus`.

**`#[cfg(test)] mod tests`:** A large test module. Notable private helper items: `parse(args: &[&str]) -> Result<Cli, clap::Error>`, `subcommand(names: &[&str]) -> clap::Command`, `FakeScreen` struct (fields `terminal`, `suspensions`, `reported`) implementing trait `Screen` (methods `size`, `draw`, `suspended`, `report_mouse`), type alias `Driven = Session<FakeScreen, Passing, Saying>` (using stub types `Passing`, `Saying` from `crate::stubs`), `session(rows: Vec<Row>) -> Driven`, `session_over(root: &Path) -> Driven`, `pressed(driven: &mut Driven, key: KeyEvent) -> bool`, `key(code: KeyCode) -> KeyEvent`, `directory(path: &str) -> Row`, `a_repository() -> tempfile::TempDir`, `rounds_until_settled(driven: &mut Driven)`, constants `DOCUMENT`, `ANSWER`, `AT_MOST`. Individual `#[test]` functions cover: CLI parsing for every subcommand and flag combination, help text content, exit-status mapping (`status_for`) including the six distinct write statuses (0,1,2,3,4,130), and `Session`-level behavioral tests (pact key descending a real repo and writing `WARLOCK.md`, un-pact removing entries, quit key opening confirmation, Ctrl-C leaving immediately, focus/mouse-toggle keys, edit key refusing on a directory row, scope prompt swallowing other keys).
