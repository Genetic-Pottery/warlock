This is the entirety of `app.rs`, the front-end state module for Warlock's TUI. It defines the in-memory representation of what the terminal screen shows and every pure operation that changes it, deliberately with no terminal, filesystem, or engine call inside it.

Structure and content:

**Module doc comment**: explains the central design idea — the engine's tree walk is flattened once into a `Row` list; collapsing, the pacted-only filter, and the file-visibility toggle are all re-filterings of that same flattened walk rather than separate data structures. It also introduces the panel (account/thread/document cards), scroll-following behavior, and states that nothing here touches a terminal, keeping the module fully unit-testable.

**Core types**:
- `Row` — one drawn line: depth, path, optional document, `NodeState`, child count, and flags for being a file, being the directory's own `WARLOCK.md`, being ignored by `.warlockignore`, and an optional scope string. Includes constructors (`new`, `file`) and builder methods (`with_child_count`, `with_ignored`, `with_document_row`, `with_scope`) plus query methods (`has_children`, `is_file`, `is_document`, `is_ignored`).
- `PactToggle` — result of toggling a pact on a directory (path + new pacted state).
- `Run` (enum: `Pact`/`Refresh`) and `InFlight`/`RunHeader`/`Summarising` — track an in-progress pact/refresh run, its directory, position/total, high-water mark, and any nested "summarising a big file" sub-progress.
- `Focus` (enum: `Tree`/`Panel`/`Composer`) — which screen area keys drive, with `next()`, `drives_the_tree()`, `drives_the_panel()`.
- `Sigils` (enum: `Nothing`/`Held`/`Unknown`) and `Chrome` — header line state (which tree is shown, what machine sigils are held), explicitly kept outside `App` since it's session-fixed.
- `App` — the main struct: `all_rows`, `rows` (filtered/drawn), `collapsible` set, `counts`, `selected`, `scroll_offset`, plus three sub-groups: `Viewpoint` (collapsed set, pacted_only, show_files, viewport height, focus), `Status` (message, in-flight run, refusal flag, mouse capture), and `Panel` (three `Card<T>` instances for account/thread/document, `showing` enum, height/width).
- `Card<T>` and `Shown` trait — generic windowing (offset, follow-newest-line flag) over account/thread/document content, with wrapping via `rows_of`.

**`App` methods** (very extensive): constructors (`from_tree`, `from_rows`, `with_collapsed`, `with_counts`); message/status setters; pact/refresh progress tracking (`set_pact_in_flight`, `set_run_in_flight`, `set_pact_summarising`, `clear_pact_in_flight`, `pact_line`, `run_header`); account/thread/document lifecycle (`start_account`, `write_run`, `close_run`, `show_document`, `refill_document`, `start_turn`, `record_turn`, `answer_turn`, `end_turn`, `swap_card`, `restore_from`); panel geometry and scrolling; view toggles (`toggle_collapsed`, `toggle_pacted_only`, `toggle_files`); pact/refresh/scope/view action decisions (`toggle_pact`, `refresh`, `scope_target`, `view_target`) each returning an `Option` and setting a refusal message when appropriate; `set_subtree_state`; `insert_file_row` (splices a newly-written document row into the tree mid-run without a reload); movement methods (`select_previous/next/page_up/page_down/first/last`, `select_row`, `select_next_by`/`select_previous_by` for pointer wheel, `scroll_panel_down/up`) all routed through a shared `movement`/`reflow`/`rescroll` machinery; focus management (`toggle_focus`, `set_focus`, `rescue_focus`).

**Free functions**: `reseat_on` (rebuilds an `App` on a freshly reloaded `Tree` while preserving all view state — selection by path, collapsed set, panel contents); `walk_of`, `node_rows`, `paint_subtree`, `moves_with_subtree`, `in_subtree`, `drawn_rows`, `pacted_rows`, `index_for`, `scroll_offset_for`, `panel_offset_for`, `file_row_position`, `count_mut`; and numerous small message-wording functions (`left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `unpacted_scope_message`, `directory_view_message`, `undocumented_view_message`, `cut_at_cap_message`, `no_document_message`, `summarising_message`, `already_running_message`, `file_row_message`, `ignored_row_message`).

**`#[cfg(test)] mod tests`**: a very large test suite (the majority of the file's length) covering flattening, selection/scrolling arithmetic, collapsing, pacted-only filtering, file toggling, pact/refresh/scope/view key behavior and refusals, ignored/scoped rows, panel/account/thread/document card windowing and follow behavior, focus cycling, pointer-driven selection/scrolling, run-in-flight/summarising footer wording, and reseating an app onto a reloaded tree (including mid-run document insertion). It uses local helper functions and fixtures (`fixture::tree()`, hand-built `Tree`/`Node` values) rather than real filesystem I/O.

No other files or definitions outside this module are shown or referenced beyond types imported from sibling modules (`warlock_engine`, `crate::account`, `crate::claude`, `crate::thread`, `crate::wrap`, `crate::fixture`).
