This file implements the `App` type: the terminal front end's state model for a tree/panel UI in a tool ("Warlock") that manages "pacts" (documentation contracts) over a directory tree.

It opens with an extensive module-level doc comment explaining the design rationale: the app flattens the engine's tree walk into a list of `Row`s for screen display; collapsing/expanding directories re-filters this flattened list rather than re-walking the tree; collapsed state is tracked by node *paths*, not row indices, so it survives tree reloads; a "pacted-only" view filter and a "show files" view filter work the same way (filter-and-reflatten, non-destructive); scrolling is tracked via a scroll offset kept in sync with selection by a pure function; a `message` field holds one-line feedback about the last keystroke, cleared on next movement; `Focus` distinguishes which of two panes (tree vs. panel) keyboard input drives; pointer/mouse operations get dedicated methods separate from key-driven movement; an in-flight pact/refresh run is tracked separately from the message (since it persists across keystrokes); an `Account` field records what a pact run has done, with its own scroll window and "follow newest line" behavior similar to the tree's scrolling.

Imports bring in `Cow`, `BTreeSet`, `Path`/`PathBuf`, `Instant`; from the engine crate: `IntoDocument`, `NodeState`, `StateCounts`, `Tree`, `to_manifest_path`; and from a local `account` module: `Account`, `Line`.

Types defined:

- `Row` — one flattened display line: `depth`, `path`, `document` (Option<PathBuf>), `state` (NodeState), `children` (count), `file` (bool, file row vs. node row), `ignored` (bool, `.warlockignore`-excluded). Constructors `Row::new` (node row) and `Row::file` (file row, borrows parent's state), builder methods `with_child_count`/`with_ignored`, and query methods `has_children`/`is_file`/`is_ignored`.
- `PactToggle` — return value of a toggle-pact action: `path` and `pacted` (bool), telling the caller whether to run or undo a pact over a subtree.
- `Run` — enum of `Pact` or `Refresh`, the two kinds of in-flight background operations.
- `InFlight` (private) — tracks an active run: `path`, `position`, `total`, `run`.
- `Summarising` (private) — tracks a sub-pass summarizing one large file within the current in-flight directory: `path`, `part`, `parts`.
- `Focus` — `Tree` (default) or `Panel`, with `other()` and `drives_the_tree()` helpers.
- `App` — the main state struct, documented field-by-field: `all_rows` (full flattened walk, source of truth), `rows` (currently drawn/filtered rows), `collapsed`/`collapsible` (BTreeSet<PathBuf>), `pacted_only`/`show_files` (view filters), `selected`/`scroll_offset`/`viewport_height` (tree selection/scrolling), `counts` (StateCounts tally), `header`/`message`, `in_flight`/`summarising`, `pact_refused`, `focus`, `account`/`panel_height`/`panel_offset`/`panel_follows`, `mouse_captured`. Derives Debug/Clone/Default/PartialEq (not Eq, due to an f64 cost field in Account), with a clippy allow for its many bool fields.

The `impl App` block holds most of the file's logic:

- Construction/building: `from_tree` (flattens a `Tree` into rows), `from_rows` (low-level constructor for arbitrary rows, used in tests), `with_collapsed`, `with_counts`, `with_scope`.
- Messaging: `header`, `message`, `set_message`.
- In-flight/run tracking: `set_pact_in_flight`, `set_run_in_flight`, `set_pact_summarising`, `clear_pact_in_flight`, `set_pact_refused`, `is_pacting`, `is_in_flight`, `in_flight_covers`, `pact_line` (builds the footer progress line with verb/fraction/summarizing/refusal suffix).
- Account/panel: `start_account`, `has_account`, `account`, `account_mut`, `take_account_from`, `panel_height`, `set_panel_height`, `panel_follows`, `panel_scroll_offset`, `panel_lines`, `panel_lines_below`, `account_line_count`.
- View state: `rows`, `collapsed`, `is_collapsed`, `can_collapse`, `pacted_only`, `toggle_pacted_only`, `show_files`, `toggle_files`, `counts`, `is_empty`.
- Selection/scrolling: `selected`, `selected_row`, `scroll_offset`, `viewport_height`, `set_viewport_height`, `mouse_captured`, `set_mouse_captured`, `focus`, `toggle_focus`, `set_focus`, `select_previous`, `select_next`, `select_page_up`, `select_page_down`, `select_first`, `select_last`, `select_row`, `select_next_by`, `select_previous_by`, `scroll_panel_down`, `scroll_panel_up`, private `movement` (dispatches to tree or panel per focus), `scroll_panel_to`, `page`, `panel_page`, `rescroll`, `reflow` (rebuilds `rows`/`collapsible` from `all_rows` applying files→pacted-only→collapsed filters in that order, re-anchoring selection by path), `moved`, `forget_last_keystroke`, `label_for` (relative-path naming for messages).
- Mutating actions: `toggle_collapsed` (collapse/expand selected row, no-op if nothing to hide), `toggle_pact` (pacts/unpacts a subtree, refusing file rows and ignored rows, returning `Option<PactToggle>` and setting a message), `toggle_refresh`/`refresh` (refreshes stale parts of a pacted subtree; refuses file rows, already-fresh pacted directories, and unpacted directories, returning the path to refresh only when the selection is a stale pacted directory, otherwise setting a refusal message and returning `None`; touches no state, tallies, accounts, or in-flight tracking itself), `set_subtree_state` (repaints every row — directory and file — under a path to a new state in both `all_rows` and `rows`, and updates `counts` by moving one tally per affected non-file row between state fields; no-ops on unmatched or already-matching paths; does not re-filter or touch the message), `insert_file_row` (splices a new file row for a path into `all_rows`, and into `rows` if shown, at the position a fresh load would give it — sorted among the parent's existing file rows, before subdirectories; used when a pact writes a document mid-run so the row appears without a full reload; no-ops if the row already exists or the parent has no row; the new row inherits the parent's current state/ignored flag; adjusts `selected`/`scroll_offset` if needed and calls `rescroll()`; does not touch `counts`, `collapsible`, or messages).

Free functions (module-level, supporting the above):

- `file_row_position` — pure helper finding sorted insertion index among a directory's file rows.
- `reseat_on(view, tree)` — rebuilds an `App` from a freshly read `Tree` while preserving the reader's view state from `view`: collapsed set, pacted-only/show-files toggles, viewport height, header, message, in-flight run, summarising state, pact-refused flag, focus, account, panel geometry. Selection carried by path (falling back to nearest surviving ancestor, else row 0). Re-filters (`reflow`) before resolving selection, then restores and re-clamps the old scroll offset. Is a no-op when the tree is unchanged.
- `node_rows` — filters out file rows.
- `paint_subtree` — sets `.state` on every row within a subtree.
- `in_subtree` — path-prefix ancestry check.
- `drawn_rows` — single pass producing visible rows given a collapsed set (skipping descendants of collapsed nodes) plus the set of paths that have children ("collapsible").
- `pacted_rows` — reverse pass keeping pacted nodes plus the ancestors needed to reach them, via a depth-based threshold.
- `index_for` — finds a row's index by exact path, else the deepest ancestor row present.
- `scroll_offset_for` — pure minimum-movement scrolling calculation for the tree pane, clamping to available rows, handling zero-viewport and whole-tree-fits cases.
- `panel_offset_for` — analogous pure scrolling calculation for the panel/account view; pins to the last screenful when following, otherwise clamps the given offset.
- Message-formatting functions: `left_on_disk_message`, `pacting_message`, `refreshing_message`, `already_fresh_message`, `unpacted_message`, `summarising_message` (appends a summarizing clause to a run line), `already_running_message` (appends an "already running" suffix), `file_row_message`, `ignored_row_message` (names `.warlockignore` explicitly).
- `count_mut` — returns a mutable reference into the right `StateCounts` field for a given `NodeState`, via an explicit match so a new state variant fails to compile if unhandled.
