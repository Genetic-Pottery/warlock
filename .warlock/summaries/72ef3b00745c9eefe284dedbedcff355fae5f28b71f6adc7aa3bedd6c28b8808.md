These are the entire contents of a Rust source module (`account.rs`) implementing the "account" data model behind warlock's TUI panel — the ordered record of what a single pact run did.

**Module documentation (top of file):** Explains the concept — a subtree pact's work is shown as an ordered list of per-directory sections, each holding an ordered list of timestamped lines. Explains the "ticking clock" design: each line's elapsed time is measured from its section's start; only the newest line in a live section counts up against a caller-supplied `now`, and it freezes the instant a newer line arrives. An empty section shows a drawn (not stored) `waiting` placeholder line. States that the module never calls `Instant::now` itself (enabling deterministic testing), and lists what is deliberately excluded: file contents, model prose, tool results, thoughts, tokens, cache stats, turn counts, API durations, and truncation logic.

**Constants:** `THINKING` = "thinking", `WAITING` = "waiting", `WRITING` = "writing" (public within crate), and `SUMMARISING` = "summarising" (private) — the fixed wording for these event types.

**Core types and their methods:**
- `Entry`: a private struct pairing an `Instant` with line text.
- `Log`: manages a section's timestamped lines and the ticking-clock rule — `opened_at`, `started`, `closed_at`, `is_closed`, `row_count`, `freeze`, `push`, `extend_or_open` (dedupes repeated identical stretches like "thinking"), `rewrite_or_open` (rewords an in-progress line like "writing · N bytes" as it grows), `rows` (yields drawable `Line`s given `now`), `shown_at`/`clock` (private helpers implementing the freeze/tick rule).
- `Outcome`: public enum of how a directory's pass ended — `Wrote { document, bytes }`, `Refused { reason }`, `Cancelled` — with a `line()` method producing the closing text, incorporating cost via a `spend` helper.
- `Section`: one directory's pass — directory path, its `Log`, accumulated `cost` (`Option<f64>`), and `has_outcome` flag. Methods: `directory()`, `cost()`, `is_closed()`, `line_count()`, `word()` (attaches an outcome line, idempotently, freezing the log).
- `Line`: public enum of every drawable row type across the whole panel (not just accounts): `Directory`, `Clocked`, `Summary`, `Text` (file lines), `Said` (user input), `Note` (warlock's own voice), `Wrapped` (overflow continuation rows). Extensive doc comments explain why each variant exists and how it differs from siblings.
- `Account`: public top-level struct — `started: Instant`, `sections: Vec<Section>`, `summary: Option<String>`. Includes a doctest example. Methods: `new`, `open_section` (freezes previous section), `record` (dispatches `Activity::Cost/Thinking/Writing/Tool` into log entries or cost accumulation), `record_summarising` (per-part-of-file progress lines), `record_waiting` (records handed-off request stats, replacing the waiting placeholder), `freeze`, `close_section`, `close_open_sections` (words every still-open section via a caller callback), `finish` (produces the final summary line with directories/wall-clock/money, noting incomplete cost reporting), plus accessors `sections()`, `started()`, `open_section_started()`, `line_count()`, `lines()`, `window()`, `rows()` (crate-private lazy iterator), and private helpers `spent()`, `unpriced()`.

**Free functions:** `clock()` (formats `Duration` as `m:ss`), `money()` (formats `f64` as `$x.xx`), `tool_line()` (shared with the thread view, formats tool name+detail), `writing_line()` (formats writing progress, zero-bytes special-cased to bare word), `continues()` (checks if a line belongs to an ongoing named stretch), `spend()` (words a cost or "no cost reported"), `size()` (public — formats byte counts as `bytes`/`KB`/`MB` with tiered precision, base 1024, using `KB`/`MB` spelling), `scaled()` (private helper for `size`), `plural()` (English pluralization helper).

**Tests module (`#[cfg(test)]`):** Large suite covering: empty runs, per-section clock resets, waiting placeholder behavior and replacement by real lines, thinking-stretch coalescing, writing-line rewording and byte formatting (including sub-kilobyte exact counts and stretch-boundary resets after other activity), waiting-line freeze/tick behavior, newest-line ticking against varying `now`, freeze-at-arrival-of-next-line semantics, closed sections staying frozen forever, run-finish freezing the live section, tool-call line formatting, summarising-pass lines (single and long runs of many parts, freeze/tick, no-live-section silence), size formatting including boundary/rounding edge cases, request-handoff lines (replacing placeholder, ordering after summarising lines, non-collapsing, no-live-section silence), cost-as-arithmetic-not-a-line, general no-live-section silence for `record`, `Outcome` line wording for Wrote/Refused/Cancelled (including no-cost-reported cases), run summary wording (plural/singular directories and passes, incomplete-cost annotation), `close_open_sections` behavior (wording all open sections, skipping already-closed ones), window/pagination slicing, `clock()` formatting edge cases, and `open_section_started()` behavior across section transitions and closures. Includes small test helpers: `at()` (instant offset), `tool()` (builds a tool Activity), and `said()` (flattens `Line`s to plain strings for assertions).
