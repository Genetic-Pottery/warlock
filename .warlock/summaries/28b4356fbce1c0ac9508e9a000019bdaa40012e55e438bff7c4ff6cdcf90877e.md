This is the whole of `running.rs`, a module implementing the headless subcommands `warlock pact <path>` and `warlock refresh <path>`.

**Module doc comment** explains the design at length: these commands reuse `pact_subtree` and `refresh_subtree` from `warlock_engine` (called the same way the `p`/`r` TUI keys call them) through `ClaudeAgent`, the crate's one process-spawning agent. It covers: the boundary check happening before any spawning (via `Opened`/`opened`, borrowed from `crate::edits`, refusing with `Error::ClosedScope` and exit status 3); progress printed as plain lines on stdout via `Progress`; failures collected and reported on stderr via `report`/`Report` with exit status 4 (`Error::Failures`); Ctrl-C handling via `listening` and a `Cancel` handle (first press cancels gracefully, exit 130; second press calls `process::exit` immediately with `CANCELLED`); a single manifest save at the end via `Manifest::save`; and environment access confined to `started`, with everything else (`ran`, `report`, `ending`) taking parameters for testability.

**Imports**: standard `io`, `path`, `process`, `sync::atomic`; `warlock_engine` (`Agent`, `PactedSubtree`, `Pacting`, `pact`, `to_manifest_path`); `warlock_tui` (`Cancel`, `ClaudeAgent`); crate-local `CANCELLED`, `descent::{Descent, carry_on, descend}`, `edits::{Opened, opened}`, `error::{Error, one_line}`.

**Struct `Progress<W: Write>`** (private) — implements `pact::Observer`. Fields: `root` (PathBuf), `out` (W), `cancel` (Cancel), `total` (usize, engine's own denominator). Methods: `new` (const fn constructor), `total` (const fn getter), `say` (writes `"warlock: {fact}"` line, ignoring write errors). Trait impl methods: `starting(&mut self, directory, position, total) -> Pacting` (checks cancel first, updates `self.total`, prints `[{position}/{total}] documenting {named}`), `documented(&mut self, directory)` (prints `documented {named}`).

**Function `named(root: &Path, directory: &Path) -> String`** (private) — spells a directory relative to root via `to_manifest_path`, falling back to `directory.display()` on failure.

**Struct `Report`** (private, derives `Debug`) — fields `lines` (Vec<String>), `failed` (usize), `total` (usize). Methods: `onto<W: Write>(&self, err: &mut W)` (writes each line prefixed `warlock: `), `status(&self) -> Error` (returns `Error::Failures { failed, total }`).

**Function `report(root: &Path, failures: &[pact::Failure], total: usize) -> Option<Report>`** (private) — builds one line per unique failing directory (deduped via `named_already`), formatted `"{directory} — {one_line(...)}"`; returns `None` if no failures.

**Function `ran(opened: &Opened, descent: Descent, agent: &dyn Agent, observer: &mut dyn pact::Observer) -> Result<PactedSubtree, Error>`** (private) — calls `descend` with opened's target/repo_root/manifest.

**Function `listening() -> Result<Cancel, Error>`** (private) — installs `ctrlc::set_handler`; uses an `AtomicBool` named `pressed` to distinguish first press (latches `Cancel`) from second (`process::exit(i32::from(CANCELLED))`). Returns `Error::Signal` on install failure.

**Function `ending<W: Write>(cancelled: bool, report: Option<&Report>, err: &mut W) -> Result<(), Error>`** (private) — returns `Error::Cancelled` if cancelled, else `Ok(())` if no report, else writes report and returns `Error::Failures` via `report.status()`.

**Function `started(descent: Descent, path: &Path) -> Result<(), Error>`** (private) — resolves environment: calls `opened`, `listening`, builds `ClaudeAgent::new().with_cancel(...)`, then calls `descended` with stdout/stderr, returning `.outcome`.

**Struct `Descended<W: Write>`** (private, `#[allow(dead_code)]`) — fields `subtree` (PactedSubtree), `progress` (Progress<W>), `report` (Option<Report>), `outcome` (Result<(), Error>).

**Function `descended<O: Write, E: Write>(opened, descent, agent, cancel, out: O, err: &mut E) -> Result<Descended<O>, Error>`** (private) — composes: builds `Progress`, calls `ran`, builds `report`, calls `ending`, returns `Descended`.

**Public functions**: `pub(crate) fn pact(path: &Path) -> Result<(), Error>` calls `started(Descent::Pact, path)`; `pub(crate) fn refresh(path: &Path) -> Result<(), Error>` calls `started(Descent::Refresh, path)`.

**Test module (`#[cfg(test)] mod tests`)** — extensive. Imports `Agent`, `Manifest`, `PactEntry`, `PactedSubtree`, `agent`, `manifest_path`, `save_sigils` from `warlock_engine`; `Cancel` from `warlock_tui`; `Descent`, `Report`, `descended` from `super`; `Opened` from `crate::edits`; `Error` from `crate::error`; `load_manifest` from `crate::session`; `closed_scope_message` from `crate::boundary`; `status_for` from crate root.

Helper functions: `a_dir()` (tempdir), `a_repository()` (builds repo with `.git/HEAD`, `alpha/lib.rs`, `beta/lib.rs`), `write(root, relative, contents)`, `holding(home, repo_root, sigils)` (calls `save_sigils`), `scoped(repo_root, module, scope)` (writes a `Manifest` with a `PactEntry` carrying `.with_scope`), `manifest_bytes(repo_root) -> Option<Vec<u8>>`, constant `CLAUDE = "claude"`.

Struct `Canned` (test fake `Agent`) with fields `root`, `refused` (Vec<String>), `cancel_at` (Option<(String, Cancel)>), `seen` (RefCell<Vec<(PathBuf, bool)>>). Methods: `refusing(root, refused)`, `cancelling_at(self, directory, cancel)`, `directories(&self) -> Vec<String>`, `saw_a_manifest(&self) -> bool`. Implements `Agent::run`.

Function `document() -> String` (filler document text), `named(root, directory)` (test helper wrapping `super::named`).

Struct `Run` (test helper) — fields `subtree`, `agent` (Canned), `lines` (Vec<String>), `err` (Vec<String>), `report` (Option<Report>), `outcome` (Result<(), Error>). Methods: `ended(&self) -> (&Result<(), Error>, Vec<String>)`, `report(&self) -> Option<&Report>`, `stderr(&self) -> Vec<String>`.

Functions: `run(repo_root, home, descent, path) -> Result<Run, Error>`, `run_refusing(...)`, `run_cancelling(...)`, `driven(repo_root, home, descent, path, agent, cancel) -> Result<Run, Error>` (builds `Opened::new`, calls `descended`), `written(bytes) -> Vec<String>`, `stored_modules(repo_root) -> Vec<String>`.

Test cases (`#[test]` fns, names are long descriptive sentences): `an_open_boundary_documents_every_directory_and_saves_the_manifest_once`, `progress_names_every_directory_from_the_root_as_it_is_entered_and_as_it_completes`, `a_closed_boundary_refuses_before_a_pass_is_spent_and_leaves_the_manifest_alone`, `a_scope_this_machine_holds_lets_the_run_through`, `a_refresh_describes_the_stale_directory_and_leaves_the_fresh_one_as_it_found_it`, `one_directory_failing_names_it_counts_it_and_leaves_the_rest_of_the_run_granted`, `a_machine_with_no_model_names_every_directory_once_and_says_how_many_of_how_many`, `a_cancel_stops_the_descent_between_directories_and_saves_what_finished`, `a_cancelled_run_says_it_was_cancelled_rather_than_naming_the_pass_it_killed`, and (Unix-only) `a_manifest_that_will_not_save_is_the_one_warlock_could_not_do_rather_than_a_four` (uses `chmod` via `PermissionsExt`, checks that running as root skips the assertion).
