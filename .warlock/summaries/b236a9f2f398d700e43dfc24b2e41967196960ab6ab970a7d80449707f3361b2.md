This is the entire contents of `ui.rs`, warlock's terminal-UI rendering module, presented as a single part covering the whole file: an extensive module-level doc comment, the module's implementation code, and a large embedded `#[cfg(test)]` test module.

**Module documentation (top):** Describes the overall screen layout — a footer along the bottom, a panel pane (left) and a bordered tree pane (right) above it — and explains the design principles: `draw` is a pure function of app state, chrome, an instant, and three optional overlay "windows" (quit confirmation, scope prompt, path prompt), with no reliance on terminal state or wall-clock reads of its own. It covers the panel's behavior (showing an account of a pact run, or warlock's ASCII-art mark before anything happens), the composer (a growing/scrolling text-entry pane under the panel), the tree window (a scrollable slice of flattened rows with collapse markers and guide lines), pointer hit-testing (`hit_test`), and the quit-confirmation overlay drawn last.

**Constants:** A very large set of named constants control formatting: indentation and guide-line glyphs (`INDENT`, `GUIDE`, `GUIDE_BRANCH`, `GUIDE_LAST`), selection/collapse markers, the compiled-in ASCII-art `MARK` (warlock's logo in block characters) plus its margins, header/run-header sizing constants, keys-line vocabulary (dozens of named key-hint strings like `ROW_KEY`, `PACT_KEY`, `FOCUS_KEY`, `COMPOSE_KEYS`, etc.) together with ordered "drop order" lists (`KEY_DROP_ORDER`, `PACTING_KEY_DROP_ORDER`) governing which key hints are dropped first on narrow terminals, footer/tree/composer sizing constants, pulse-animation timing (`PULSE_PHASE`), and constants for the quit-confirmation window and the scope/path prompt window (headings, margins, rules text, cursor glyph).

**Core functions:** Layout cutting (`areas`, `split_column`, `tree_width`, `pane_inner`, `panel_split`, various `*_height`/`*_width` public helpers used by the caller to size viewports before drawing), a `Hit` enum and `hit_test` function mapping screen coordinates to UI regions, drawing functions for each region (`draw_panel`, `draw_run_header`, `draw_mark`, `draw_composer`, `draw_tree_pane`, `draw_header`, `draw_tree`, `line` for one tree row, `guide_prefixes` for computing tree guide glyphs, `pulse_colour` for the pulsing in-flight row animation, `draw_footer`, `draw_confirm`, `draw_scope` for both scope- and path-prompt windows), plus text utilities (`truncated`, `clipped`, `laid_out_keys`, `display_width`, `centred`).

**Test module (bottom, very large):** Hundreds of unit tests using an in-memory `ratatui` `TestBackend` to render frames and assert on buffer contents — covering tree row rendering, guides, collapse/expand markers, file rows, scope labels, pulse animation colors, footer tally/keys-line layout and truncation behavior at various widths, panel/account/thread/document card rendering and swapping, run-header rendering and scrollback indicators, composer sizing/muting/focus behavior, hit-testing correctness, and the quit-confirmation and scope/path prompt overlay windows (sizing, centering, covering underlying content, clamping on tiny terminals, highlight state, refusal messages, etc.).
