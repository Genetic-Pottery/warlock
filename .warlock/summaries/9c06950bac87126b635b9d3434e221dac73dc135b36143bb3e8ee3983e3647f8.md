This is the complete contents of `claude.rs`, the transport layer implementing the "agent seam" between warlock-engine and the `claude` CLI child process. It is organized as: an extensive module-level doc comment, imports, constants, types, functions, and a large `#[cfg(test)]` module.

**Module doc comment** explains the file's purpose: running `claude` as a child process for two kinds of runs (documentation passes via `ClaudeAgent`, and conversational turns via `ChatAgent`), and the concurrency hazards it must avoid (pipe deadlock, EOF handling, `wait()` blocking, cancellation, and progress reporting).

**Constants**: `INVOCATION_TIMEOUT` (5 min, pub), `PROGRAM` ("claude"), `ARGS` (base CLI flags), `MODEL` ("claude-sonnet-5"), `CONTEXT_TOKENS` (200_000, pub), `EFFORT` ("low"), `BRIEF_EFFORT` ("high", pub), `BRIEF_MODEL` ("claude-opus-5", pub), `SYSTEM_PROMPT`, `NO_TOOLS`, `CHAT_TOOLS` ("Read,Grep,Glob"), `CHAT_SYSTEM_PROMPT`, `BRIEF_ARTIFACT`, `BRIEF_ARGUMENT`, `CHAT_INSTRUCTION` (pub), `WRITE_INSTRUCTION` (pub), `MODEL_VAR` ("WARLOCK_MODEL"), `EFFORT_VAR` ("WARLOCK_EFFORT"), `CONTENT_GUARD`, `POLL_INTERVAL` (10ms).

**Public functions**: `brief_instruction(template: &str) -> String` (pub, builds the `/brief` prompt from a template).

**Private functions**: `or_default`, `overridden`, `render(request: &agent::Request) -> String`, `default_args`, `chat_args`, `session_id() -> String`, `read<R>` (thread reading stdout incrementally), `drain<R>` (thread reading stderr wholesale), `collect<T>`, `watch`, `kill_and_reap`, `lock`, `invoke` (the shared spawn/read/wait/timeout/cancel orchestration), `judge`, `cancelled`.

**Types**:
- `Session` (private struct: `id: String`, `claimed: Arc<AtomicBool>`) with methods `new`, `args`, `claim`.
- `SESSIONS: AtomicU64` (static).
- `Cancel` (pub struct, `Clone + Default`) wrapping `Arc<State>`; methods `new`, `cancel`, `is_cancelled`, `register`, `finished`. Private `State` struct with `cancelled: AtomicBool`, `running: Mutex<Option<Arc<Mutex<Child>>>>`.
- `Activity` (pub enum, `Debug, Clone, PartialEq`): variants `Tool { name, detail }`, `Thinking`, `Writing { bytes: u64 }`, `Cost { usd: f64 }`.
- `Activities` (pub struct, `Clone`) wrapping `Arc<dyn Fn(Activity) + Send + Sync>`; methods `new`, `none`, `report`; implements `Default`, `Debug`.
- `Wired` (pub trait): `fn wired(&self, cancel: Cancel, activities: Activities) -> Self`.
- `Converses` (pub trait, extends `Wired`): `fn turn(&self, message: &str) -> Result<String, agent::Error>`, `fn raised(&self, model: &str, effort: &str) -> Self`.
- `ClaudeAgent` (pub struct, `Debug, Clone`): fields `program`, `args`, `timeout`, `cancel`, `activities`. Methods: `new`, `with_program`, `with_args`, `with_timeout`, `with_cancel`, `with_activities`, `program`, `args`, `activities`, `timeout`, `spawn`, `spawn_error`. Implements `Default`, `Agent` (methods `run`, `context_tokens`), `Wired`.
- `ChatAgent` (pub struct, `Debug, Clone`): fields `program`, `args`, `session: Option<Session>`, `timeout`, `cancel`, `activities`. Methods: `new`, `with_program`, `with_args`, `at_effort`, `at_model`, `replacing`, `with_timeout`, `with_cancel`, `with_activities`, `program`, `args`, `activities`, `timeout`, `turn`, `spawn`, `spawn_error`. Implements `Default`, `Wired`, `Converses` (delegating `turn` to `Self::turn`, and `raised`).

**Submodule `stream`** (private, `mod stream`): parses `--output-format stream-json` lines using `serde_json::Value`. Contains `DETAILS` (const list of tool-name→argument-key pairs), `Reading` (struct: `activities: Vec<Activity>`, `text: Option<String>`, `opens_text: bool`), and functions `read_line`, `read_activities`, `read_block_start`, `read_text_delta`, `read_block`, `read_detail`, `read_result` — all pure parsing functions with no I/O.

**Test module** (`#[cfg(test)] mod tests`): extensive unit tests covering `render`, `or_default`, `session_id`, argument-building for both agent types, `brief_instruction`/`CHAT_INSTRUCTION`/`WRITE_INSTRUCTION`, and `stream::read_line` parsing behavior (tool calls, thinking, text deltas, result lines, garbage input). Contains a nested `#[cfg(unix)] mod unix` with real child-process integration tests (using `/bin/sh`, `/bin/cat` as stand-ins) covering timeouts, cancellation, zombie reaping (`#[cfg(target_os = "linux")]` subset), pipe deadlocks, and a further nested `mod turns` testing `ChatAgent` specifically (stdin passing, activity reporting, cancellation, timeouts). Test helper functions include `args`, `turn_args`, `value_of`, `is_uuid_shaped`, `assistant`, and within the unix submodules: `stand_in`, `printing`, `listening`, `drained`, `is_cancelled`, `pid`, `scratch`, `clean_up`, plus constants `PASS`, `DOCUMENT`, `TURN`, `ANSWER`, `AT_MOST`.
