This is the complete contents of `editing.rs`, a source file implementing the "edit" keystroke (`e`) for a terminal UI tool called warlock. It is presented as one whole part.

**Module-level doc comments** open the file, explaining the design: pressing `e` resolves the selected file, reads `$EDITOR`, suspends the terminal, runs the editor as a foreground child, and reconciles state afterward. Key points documented: warlock itself never writes to files (the child editor does); editing a `WARLOCK.md` restales its own directory since it's part of the hashed subtree; the row-level refusal wording comes from `App::view_target` (shared with `view_press` in `crate::viewing`); an in-flight run is refused via `App::set_pact_refused` before the row is even checked; `$EDITOR` is split on whitespace only (no shell, no quoting support), never falling back to `VISUAL` or a default editor; three outcomes (success, non-zero exit, spawn failure) all restore the terminal, with the two failure cases writing one line to `App::message`; and afterward both the tree (via `reload_tree`) and possibly the document card (via `App::refill_document`) are re-read.

**Imports**: standard library (`OsStr`, `Path`, `PathBuf`, `Command`, `env`, `io`), plus `warlock_engine::{Viewed, view_file}`, `warlock_tui::App`, and crate-local `error::one_line`, `session::{Scope, note, reload_tree}`, `terminal::Screen`.

**Constants**:
- `EDITOR_VAR: &str` — private, value `"EDITOR"`, the only env var read.
- `NO_EDITOR: &str` — private, the footer message shown when `$EDITOR` names nothing runnable; documented to cover unset/empty/whitespace-only/non-UTF8 cases.

**Struct**: `Editor` (private, derives `Debug, Clone, PartialEq, Eq`) with fields `program: String` and `args: Vec<String>` — parsed representation of `$EDITOR`.

**Functions**:
- `edit_press` (`pub(crate)`) — the entry point for the keystroke; signature `(app: &mut App, screen: &mut impl Screen, scope: &Scope, showing: Option<&Path>, mouse: bool, in_flight: bool) -> io::Result<()>`. Resolves target file via `edit_target`, resolves editor via `editor_command`, suspends the screen via `Screen::suspended`, runs `run_editor`, then calls `came_back`.
- `came_back` (private) — signature `(app: &mut App, scope: &Scope, edited: &Path, showing: Option<&Path>)`. Reloads the tree via `reload_tree`; if `showing == Some(edited)`, re-reads the file via `view_file` (from `warlock_engine`, returning `Viewed { text, cut }`) and fills via `app.refill_document`, or on error calls `note(app, one_line(...))`.
- `edit_target` (private) — signature `(app: &mut App, in_flight: bool) -> Option<PathBuf>`. Checks `in_flight` (calls `app.set_pact_refused()` and returns `None`), else defers to `app.view_target()`.
- `editor_command` (private) — signature `(value: Option<&OsStr>) -> Option<Editor>`. Parses via `split_whitespace`, returns `None` for empty/non-UTF8 values.
- `run_editor` (private) — signature `(editor: &Editor, path: &Path) -> Option<String>`. Uses `Command::new(program).args(...).arg(path).status()`, inheriting stdio; returns `None` on success, `Some(String)` messages on non-zero exit or spawn failure.
