This is a single, complete Rust source file (not split across parts) implementing an "account" data structure for warlock's TUI panel — an ordered, replayable record of what one pact run did, directory by directory, with a self-contained clock model that requires no wall-clock reads of its own.

**Module-level content**: extensive doc comments explain the purpose (minutes of work as evidence a run is alive, not hung), the ticking-clock design (each line's displayed time is measured from its section's start; the newest line's clock is a function of a caller-supplied `now` and freezes the instant a newer line arrives; an empty section shows a drawn-not-stored `waiting` placeholder), and what is deliberately excluded (file contents, model prose, tool results, thoughts, tokens, cache stats, turn counts, API durations, truncation).

**Constants** (crate-private unless noted):
- `pub(crate) const THINKING: &str = "thinking"`
- `pub(crate) const WAITING: &str = "waiting"`
- `pub(crate) const WRITING: &str = "writing"`
- `const SUMMARISING: &str = "summarising"` (private)

**Private struct** `Entry { at: Instant, text: String }` — one clocked line.

**Crate-private struct** `Log { started: Instant, entries: Vec<Entry>, closed: Option<Instant> }`, shared between a pact's `Section` and a panel thread's turn. Methods: `opened_at` (const), `started` (const), `closed_at` (const), `is_closed` (const), `row_count`, `freeze`, `push`, `extend_or_open`, `rewrite_or_open`, `rows` (returns iterator of `Line`), private `shown_at`, private `clock`.

**Public enum** `Outcome` (non-exhaustive-style, three variants): `Wrote { document: PathBuf, bytes: u64 }`, `Refused { reason: String }`, `Cancelled`. Private method `fn line(&self, cost: Option<f64>) -> String`.

**Public struct** `Section { directory: PathBuf, log: Log, cost: Option<f64>, has_outcome: bool }` (fields private). Public methods: `directory()`, `cost()` (const), `is_closed()` (const); private: `line_count`, `word`.

**Public enum** `Line` — flat drawable row type shared across account/thread/document cards. Variants: `Directory { path: PathBuf }`, `Clocked { clock: String, text: String }`, `Summary { text: String }`, `Text { text: String }`, `Said { text: String }`, `Note { text: String }`, `Wrapped { text: String, heading: bool }`.

**Public struct** `Account { started: Instant, sections: Vec<Section>, summary: Option<String> }` — the main type, `PartialEq` but not `Eq` (holds `f64`). Includes a doctest example importing `warlock_tui::{Account, Activity, Line}`. Public methods: `new` (const), `open_section`, `record` (matches on `Activity::Cost`, `Activity::Thinking`, `Activity::Writing`, `Activity::Tool`), `record_summarising`, `record_waiting`, `close_section`, `close_open_sections`, `finish`, `sections`, `line_count`, `lines`, `window`; crate-private: `freeze`, `started`, `rows`; private: `spent`, `unpriced`; public `open_section_started`.

**Free functions**: `fn clock(elapsed: Duration) -> String` (private), `pub(crate) fn money(usd: f64) -> String`, `pub(crate) fn tool_line(name: &str, detail: Option<&String>) -> String` (shared with thread rendering), private `fn writing_line(bytes: u64) -> String`, private `fn continues(text: &str, word: &str) -> bool`, private `fn spend(cost: Option<f64>) -> String`, `pub fn size(bytes: u64) -> String` (public, base-1024, spells "KB"/"MB", noted as disagreeing in spelling with the engine's "KiB" usage while agreeing numerically), private `fn scaled(bytes: u64, unit: u64, name: &str) -> String`, private `fn plural(count: usize, one: &str, many: &str) -> String`.

References to external items not defined here: `Activity` (from `crate::claude`), `Thread` and `Turn` (from crate root, `crate::Thread`/`crate::Turn`), `mod@crate::wrap`.

**Test module** `#[cfg(test)] mod tests`: imports `Account, Line, Outcome, Section, clock, size` and `Activity`; helper functions `at`, `tool`, `said`; a large suite of unit tests covering section clocks freezing/ticking, waiting placeholders, thinking/writing coalescing and rewriting, summarising-pass lines, request/waiting lines, cost accumulation, outcome wording (`Wrote`, `Refused`, `Cancelled`), summary line formatting (including singular/plural and incomplete-cost cases), `close_open_sections` behavior, windowing (`window`/`lines`), `clock` formatting, and `open_section_started` semantics.
